# 衣架设备：仅充电口的防水设计范围

日期：2026-10-28。用户最新澄清：防水仅考虑充电口，其他部位不考虑。本版替代上一版整机分区、膜、冷凝和雨后恢复的防水工作范围；旧讨论保留在 Git 历史。取消太阳能的决定不变。

## 1. 当前范围

只研究充电口的位置、封盖、插拔操作及其受水路径。主机外壳其他部位、传感器、线缆及雨头的防水结构和整机 IP 验收均不纳入当前任务；这是范围撤回，不是完成了相应验证。

充电接口、封盖材料和几何尚未冻结。下列内容是 T12 待比较的候选，不能写成用户已经选定或已验证的产品规格。

## 2. 候选设计与输入

| 项目 | T12 比较内容 | 交付条件 |
|---|---|---|
| 位置 | 在主机可用空间内比较接口朝向、滴水路径和插头净空 | 布局图同时标挂衣、取下、插拔姿态，不预设已完成防护 |
| 封盖 | 比较带连接带的保护盖、盖合接触面及用户开合操作 | 记录所占空间、零件与成本假设；接口本体是否带密封另按候选规格核对 |
| 操作 | 区分盖好未充电、开盖未连接、连接充电、拔出再盖好 | 建议取下并在干燥处充电；是否支持边充边测由充电热预算决定 |
| 状态来源 | 充电连接/结束仅使用真实可得输入或明确标为合成的测试事件 | 未配置开盖/端口湿度检测器时，不能声称软件知道封盖或受水状态 |

## 3. 验证安排

现在只做尺寸/进水路径示意、操作检查和测试用例设计，不采购、不制作。未来有实物后再验证所选接口在规定盖合状态和安装姿态下的受水情况，以及反复插拔/开合后的表现；打开封盖和连接充电作为不同操作条件记录。当前没有端口防水通过结果。

不因此新增端口湿度传感器、自动湿插禁止或整机 IP 目标。若后续用户改变范围，再更新要求和验收。
