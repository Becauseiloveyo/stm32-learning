# 阳台衣架设备：防雨、冷凝与测量可靠性设计

日期：2026-10-28。用户新增防水要求的设计补充。当前无实物，本文是候选结构、算法输入边界和未来验证计划，**不声明任何 IP 等级、浸水能力或防水通过结果**。产品已取消光伏，供电候选为电池与人工充电。

## 1. 先定义使用边界

当前拟覆盖阳台挂衣过程中的湿衣滴水、短时雨滴/风驱飞溅、温湿变化和冷凝风险。是否长期完全露天、冲洗、浸泡、随衣机洗，尚非已确认能力；第一版不把这些情况纳入承诺。此边界是设计建议，最终适用范围需实测确认。

器件、防水膜或连接器自身的等级不能直接成为整机等级。若后续选择 IP 目标，需要针对完整装配件、封盖状态、安装姿态和规定试验确认；本轮只查阅 IEC 60529 官方介绍，没有购买或执行标准试验。[W03](#8-来源与证据边界)

## 2. 分区，而不是把整个装置灌封

| 区域 | 候选结构 | 必须保留的功能/限制 |
|---|---|---|
| 控制与电池区 | 独立防护壳、周边密封、避开向上积水的接缝、明确线缆密封与应力释放 | 不与测湿气路共用积水通道；电池发热、泄压和检修要求另按器件核对，不能随意全灌封 |
| 环境参考探头 | 遮阳挡滴、向下/侧向受保护气口，兼容的透汽保护膜或滤帽作候选 | 要测到环境空气；不能完全封死，也不能吸入主机热气或湿衣局部蒸气 |
| 衣物局部探头 | 可排水的外层挡滴结构、局部气路与电子区隔开，小死体积 | 保留原测量对象与覆盖面积记录；防水结构改变气路时必须重新核对模型参数 |
| 润湿/雨头 | 独立外露感应表面，连接和背面作防护，避免从其积水区向主机引水 | 感应面需要接触来水；传感面涂层厚度/材料影响电容与残留，不能任意涂覆后沿用阈值 |
| 线缆/接头 | 合适的线缆引入、密封和拉力承载，外部走线形成滴水回路 | 防止沿线缆进水；不可把一根未密封的线穿壳后当防水，风摆和重复拉动需后续验证 |
| 人工充电口 | 可拆主机或带可靠封盖的接口作比较；建议在室内干燥条件充电 | 封盖打开的状态不沿用关闭时的防护假设；湿态/端口状态检测尚未实现，不能声称自动阻止湿插充电 |

排水应在挡滴外腔/湿区完成，不是在电池舱底直接开孔并仍称密封。多个功能区的隔壁、膜边缘、胶缝和固定件一起构成防护路径。

PCB 防护涂层只能作次级措施。湿度敏感开口不能被普通三防漆或胶覆盖；装配污染、胶挥发物、连接器和天线影响也需核对。Sensirion 的设计指南区分工作时的滤膜与生产期间的临时保护盖，不能混用。[W01](#8-来源与证据边界)

## 3. 为什么防水会影响算法

防护壳可能增加死体积或改变通风；水膜/积水也可能使采样失去代表性。因此“电子元件没坏”和“读数仍能用于判干”是两个验收目标。

部分原厂集成滤膜在规定结构下可保持较快响应，不能一概认为加膜必然很慢；也不能把原厂封装的性能复制到自制外壳。装壳后的响应、温度耦合和滴水后的恢复要另行约束。[W01](#8-来源与证据边界)

T10 后续观测层至少记录以下语义，具体字段由算法任务版本化定义：

- `observation_health`：有效、疑似受水/阻塞、恢复中、未知；附原因和证据时间。
- 响应模型/误差来源、安装身份、是否处于传感器加热或充电热扰动阶段。
- 本地润湿事件及雨头自身健康状态，与温湿度探头的健康状态分开。

这些是输入语义，**不是已实现的受水检测器**。只有实际可得的检测/用户事件才能作为健康证据，仿真内的真实积水状态不得直接泄漏给估计器。仅有高 RH 不能证明探头受水；没有雨头事件也不能证明探头干燥正常。

拟定处理：

1. 已知受水、气口阻塞或加热干扰时，不将相关读数作为正常环境观测更新参数，旧预测须标失效/受限，不能继续呈现为当前可信结果。
2. 恢复期不是“固定等几分钟即可靠”。未来恢复标准应结合实际响应验证、可得健康证据和安装条件；未标定时保留未知，旧预测可作带时间的历史记录。
3. 雨头湿润不等于衣物吸水质量已知；对水量未知的再湿事件扩大状态范围或暂停有效 ETA，不能从二值雨头编造 `R_j`。
4. 若主动测量气路加了膜/挡滴结构，先重估传质/通风与响应，避免在传质阻力和传感器滤波里重复计算同一效应。

M1 先完成开放织物热湿模型，在契约里预留以上边界；M2 实现观测/集合时必须纳入相应失败情景。T12 才具体比较机械/保护结构，T11 接入故障和过期通知。

## 4. 冷凝与日晒同样重要

密封壳内可能原本就有水汽，温度变化后仍可能冷凝；防外部水进入不等于内部不会结露。透气件是压力和湿气管理候选，能否改善取决于安装、温湿变化及材料，不能保证杜绝冷凝。[W02](#8-来源与证据边界)

建议同时比较壳体热路径、装配时含湿、受保护通气位置及干湿周期。参考探头与主机/充电区隔热，避免日晒后偏热；电池温度范围按后续具体器件制定，不在本轮虚构统一充电温度门限。

不把干燥剂放进测湿采样腔：它会改变测量对象。若研究主机舱内的吸湿材料，需要有有限容量、维护和饱和后行为，不能将它当作免维护防水方案。

## 5. 验证矩阵：现在做什么，以后测什么

| 情景 | 当前电脑阶段 | 未来实物证据 |
|---|---|---|
| 湿衣滴水/斜向飞溅 | 标出进水路径、滴落点及湿/干区边界 | 不同姿态、接缝/连接/电池舱的渗水检查 |
| 膜/气口水膜覆盖 | 注入观测迟滞、饱和、缺测/失效；检查不会误收窄 ETA | 对照参考测量装壳响应及雨后恢复时间，数值不能用合成值替代 |
| 真实高湿但未受水 | 检查不因 RH 高就直接判下雨或探头损坏 | 高湿环境与凝露/直接滴水分开的对照 |
| 夜间冷凝/日晒降温 | 温湿/表面温度场景及健康未知处理 | 热湿循环、内部凝露、绝缘/腐蚀和信号恢复 |
| 雨头受水而衣服未受水 | 风险提醒与衣物水量分开 | 部署位置与衣物实际受水对应关系 |
| 洗衣液残留/灰尘/污物 | 污染偏置或膜性能未知的压力情景 | 相容性、污染与清洁后响应；不套用纯水测试结论 |
| 插口封盖开/未装好 | 标记防护状态未知，充电热阶段不当正常观测 | 插拔、封盖磨损、端口受水与充电路径验证 |
| 拉动/跌落/反复开合后 | 安装事件失效与结构薄弱点审查 | 密封保持、线缆拉力及再次受水试验 |

软件故障注入只验证错误处理，结构图只验证描述的路径，不是 IP 试验。实物参数和合格数值留给 H01；任何“无渗水”“恢复正常”结论都必须有独立参考和记录。

## 7. 对任务的影响

- T10 M1 专用对话实现前向模型；本轮防水补充由协调者维护，不侵占算法文件所有权。
- T10 M2 新增受水/恢复/未知健康的观测失效测试，不把这些元数据的存在写成已具备硬件检测能力。
- T12 的结构评审加入湿/干区、膜边界、排水/线缆/充电口、热与冷凝；面积与成本需计入这些部件。
- T11 的界面和消息区分受水风险、传感器不可用、预测过期及恢复；高湿不自动确认降雨。
- T08/H01 必须审查所选防护目标与实测证据，不能凭某个器件有等级就宣称整机达标。
