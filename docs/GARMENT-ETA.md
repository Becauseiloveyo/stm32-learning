# T10 M2b：条件情景目标时间

本包是未标定的电脑情景计算，非衣物实时估计、传感器反演、真实收衣提醒或概率预测。`scenario_only`、`observation_mapping=unavailable`、`collection_authorized=false`，所有成员、目标和未来环境为 `SYNTHETIC_UNCALIBRATED`，seed=null。M1/M2a 均限定范围验收；当前没有中央温湿度到含水量的可信映射，因此本包不读取 RH 观测、不从观测或生成真值校正先验。未接触中央不开展衣物干燥记录；本包不创建记录，也不验证接触。

## 输入与假设

`eta.py::calculate` 只接受显式白名单：合成人为设定的 `members`、分段未来 `scenarios`、`target_x`、`step_s`、`computed_at_s`。未知字段（包括隐藏真值、材料标签或未来实际天气）拒绝。调用方需确保未来输入确为事先声明的情景，而非事后实际天气；字段校验无法证明输入来源真实。绝不把生成器隐藏状态当成给定初值，真实未知时必须由外部明示宽范围或保持未知；本包仅计算所列成员，不声称穷尽现实。成员 ID 是合成配置标签，不是材料分类。

示例参数在 `config.json`，以 M1 已登记的合成两区参数为基础，变换慢区阻力/水活度尺度，初始 X 依次为 (0.3,0.5)、(0.6,0.9)、(0.9,1.2) kg水/kg干布，最后一组慢区阻力和 X_b 乘 1.7。初温各 25°C；合成目标两区 X ≤ 0.3 kg/kg，时域 14400 s，步长 20 s，`computed_at_s=0` 为情景起点；环境维持、3600 s 后高湿遮阴、通风变化及 3600–7200 s 指定雨水等分段值均在配置中。X、各面积、温度、流量、辐照及物性单位和软件域沿用 M1 `parameter_registry.json`，未来驱动以 M1 的 `Drive` 字段显式给定。每个区的质量和区域比例均为合成假设，不是对应实际面料或探头的参数。目标不是已标定的收衣阈值。

## 端点、失败及时间分辨率

每个成员与每个情景使用 M1 的两区前向模型，驱动切换时把步长截到分段边界。**仅当同一采样时刻两区均满足目标**才记录首次达到；不能取各区各自首次穿越的较大值，因为先达到的区可能在另一地区达到前再湿。继续推进至时域末，记录达到后是否在后续采样点出现任一区重新超过目标；该标记不保证持续满足，亦不设任意等待时间。

这是 `first_joint_sample_s`，即相对情景起点的首次共同满足**采样点**，并保留之前一个采样时刻及步长；不是精确连续穿越时间，也不是保证前后区间内真实首次事件的严格包围。尤其两个区可能在相邻采样点间同时短暂满足又再湿，算法会漏检；步长收敛和解析对照仅约束所测情景，不证明任意时间分布的误差上界。要展示为时间范围时须保留采样分辨率，不能宣传精确秒数。

每个组合均保留为 `reached_sampled`、`not_reached_within_horizon`、`outside_domain_or_invalid_member` 或 `numerical_step_failure`，附原因；未达目标、超域、积分失败都不丢弃。存在任一未解决组合时 `upper_sample_s=null`，无论其他组合是否达到，代表有限上界未知；仅全部组合达到才报告已计算样本点的最大值。`earliest_known_sample_s` 只指成功案例的已知最早采样点，不是所有可能现实或失败成员的下界。运行失败发生在已记录首次样本之后仍使该组合未解决，并保留先前样本供诊断。其他边界/非有限驱动由 M1 逐段验证；结构非法、缺少字段、负步长或时段乱序直接拒绝请求，不用缺省零填充。

## 实际示例与解析检查

12 个成员×情景组合中，4 个在时域的采样点共同达到目标，8 个未达到；采样点最早 5780 s，存在未解决成员，所以上界未知。该数值只描述手选合成情景，不是预测实物的剩余时间。合成测试另构造两区线性排液、无传热和蒸发的退化解析极限 `X_j=X0_j exp(-k_j t)`：X0=(0.8,0.6)、k=(0.001,0.0005) 1/s，目标 0.3，精确共同首次达到约 1386.29 s；10 s 采样为 1390 s，1 s 为 1387 s。该测试仅在解析情景中证明采样误差小于相应采样间隔。另一测试在普通区先达到后加入人为雨水、另一地区随后达到时普通区已再湿，正确输出未达共同采样目标，而非使用各自首次穿越的最大值。同温雨水加线性排液的退化对照满足 `X(t)=Xeq+(X0-Xeq) exp(-kt)`，Xeq=R/(k m_d)=0.2；X0=0.8、目标 0.3 的解析时间约 1791.76 s，10 s 网格检出 1800 s；目标 0.2 或 0.1 在有限测试时域未检出，不能把平衡附近数值舍入当成严格有限穿越证明。退化验证不是实际衣物实验。
