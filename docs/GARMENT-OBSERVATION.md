# T10 M2a：中央观测契约与条件反例

本包是电脑端研究接口与有条件的不可辨识性例子，不是实物传感器、接触检测器、全衣估计器、干燥判断或 ETA。全部情景为 `SYNTHETIC_UNCALIBRATED`、seed=null，`collection_authorized=false`。协调验收状态以全局状态和收据为准。M1 两区域是计算结构，不代表两个设备或两个已批准的探头，不能推断中央必为慢区。目标位置是衣架底部横杆中央，未接触该处不开展衣物干燥记录；尚未确定接触检测方式，不新增硬件。

## 可得输入及质量语义

`contract.py::observe(packet, policy)` 接收**严格白名单**，本接口没有真值、面料标签或未来天气字段。输入须事先由外部实际可得来源提供，字段集错误即拒绝；生成器的 `project_packet` 只复制允许的顶层观测，子字段也严格核对。以下是接口或候选输入，不宣称设备已经具备。

| 字段 | 单位/软件范围 | 来源与缺失 |
|---|---|---|
| `now_s`、测量和收到时间、证据区间及签发时间 | s，有限且非负；采集 ≤ 接收 ≤ 当前 | 同一单调时钟域的相对时间；跨设备须先同步，未知时间不能假定为当前 |
| `installation_id` | 非空字符串 | 外部安装标识；身份改变的跨批次历史处理不在本包 |
| `ambient_temp` / `local_temp` | °C，0–50 | 假定可得的环境/中央局部温度；仪器、操作输入或合成输入，无法提供则 null |
| `ambient_rh` / `local_rh` | 比例 0–1 | 假定可得的空气湿度，非布料含水量；缺失 null。旧 `MEASUREMENT-CONTRACT` 使用 %RH，本包用比例，转换必须显式除以 100；未实现旧协议适配 |
| 每个样本 `uncertainty_abs`、`source` | 各通道同单位；非负有限 | 输入方提供的绝对误差界和来源；未知误差不得填 0 冒充已知；示例数值合成，不是厂商规格或置信区间 |
| `contact` | confirmed / not_contact / unknown | 外部声明接触有效、未接触或未知；非未知需显式覆盖区间及签发时间；unknown 不携带证据；读数弱、仿真真值不可自行证明接触。`synthetic_external` 是演示假设，不是已实现的检测 |
| `charging_heat` | known_interference / no_known_interference / unknown | 外部声明热干扰状态、覆盖区间及签发时间；无证据为 unknown，不能假设无干扰 |

本包没有风、辐照或雨的实测入口；它们不是零。M1 中是生成器侧明确的合成情景。二值雨头不能得出衣物吸水量。输入时间、来源、误差仍须在未来具体系统中核实；“外部确认”不保证其可靠性。空气温湿度即使存在也不自动成为衣物直接含水读数。

政策数值仅是合成代码检查：最大样本年龄 120 s、传递延迟 20 s、通道间测量时间偏差 30 s、接触/热证据签发年龄 120 s；误差界上限温度 0.5°C、湿度 0.05 比例（5 个百分点）。来源与实际值存于 `config.json`；均非经验证有效时限或硬件性能。负数、非有限、未来或倒序时间、未知字段、错误单位/类型/数值出域拒绝；空样本、陈旧或过大误差、时间不一致和已知/未知热扰动使记录条件不满足并给出原因。门限比较只证明声明值满足合成软件规则，不证明误差声明真实，也不实现动态传感器延迟或校准。

接触和充电热证据均须给出 `coverage_start_s`、`coverage_end_s`、`issued_at_s`，遵守 `0 ≤ start ≤ end ≤ issued ≤ now`；未知状态的来源和三个时间均为 null。**覆盖区间由外部明确声明**，不是由某次点状观察、等待时间或新鲜度自动推断：签发时间晚于采样时刻时，仅当证据明确追溯覆盖该时刻才接受，不能把 595 s 的点证据当成覆盖 590 s。覆盖边界为闭区间。接触区间须覆盖两个已提供的局部样本测量时刻；热干扰区间须覆盖所有已提供的环境及局部样本。每个必要通道仍须存在，缺测不能凭剩下的样本授权。已知热干扰始终拒绝有效记录。

声明的接触区间未覆盖全部局部样本时，`contact_state_effective=unknown`；如未接触声明只覆盖部分局部样本，另保留 `contact:not_contact_evidenced` 原因，不把其余时刻当作确认接触。完整覆盖的未接触状态为 `not_contact`。过期依据签发时刻，但未过期仍不能替代覆盖检查。`contact_state_effective` 描述该组样本时刻的有效性，不能推断当前时刻的接触状态。外部证据是否可靠、如何支持连续或追溯区间尚无实验验证，也未实现自动检测。

`local_record_allowed=true` 只表示当前包的接触证据、输入完整性和合成质量门限满足，可以作为**局部研究输入**；不是衣物已干或全衣测量。`not_contact` 不允许衣物干燥记录；`unknown`、接触证据过期或其他质量问题也不允许提升为有效记录。包不实现持久记录；调用方可留明确的诊断数据，但不得将诊断当有效衣物历史。`whole_garment_state` 恒 unknown。本接口无 ETA 或概率。

## 局部映射及无法闭合的边界

T09 第 5 节中气路关系可写为 `V dρ_c/dt=A_cov J_cov+Q(ρ_a-ρ_c)+m_dot_wall`，且 `J_cov=(a_w ρ_sat(T_g)-ρ_c)/(r_a,c+r_i)`。理想读取空气温湿度时 `RH_c = ρ_c/ρ_sat(T_c)`，还需气腔温度及仪器响应、噪声和采样：这些只是一种候选关系，不能将织物的 `X` 直接送到传感器字段。若覆盖模型将来可闭合，开放面积和覆盖面积必须分开，统一质量流和潜热支出，不得在 M1 的全开放蒸发之外再额外扣同一区覆盖蒸发。当前 M1 是开放织物，不能将上式单向后处理为有反馈的腔体模型并声称账目一致。

中央接触几何、覆盖面积、腔体交换、壁库存、表面温度、时间响应及与两计算区的对应均未知；腔体温度变化时还缺热闭合。故本包不调用旧局部模型、不合成线性加权传感器或从 X 直接生成读数。明确留给未来：若实际观测方案与参数有依据，再建立严格的来源/时序/覆盖和守恒契约；目前不能从这四个输入反演局部或全衣水量。

## 可重放的条件反例

`witness.py` 只在生成侧调用已验收 M1 前向模型。两个合成案例假设普通计算区代表中央，其参数、初值、环境和驱动完全相同；另一独立区初始干基水量分别 0.3 与 1.2 kg/kg，干重 0.1 kg。此对应只为反例条件，**不是项目默认映射或已知传感器位置**。M1 无跨区迁移，因此相同中央输入给出相同中央轨迹。取 0、300、600 s，生成侧分别记录理想中央局部 `X`、水量和温度，逐点相同；这是假设可以完美观测中央真实状态的理想上界，不是可得传感器读数，不送入消费者。若进一步假设实际局部观测仅依赖相同的中央过程及相同环境、且无其他区域传入影响，局部观测也不能区分两例；这一映射和假设未实物验证。演示包中的环境/局部 RH 是人工填写的接口样例，**不是模型生成或拟合的湿度曲线，不作为两案例物理相容性的证据**。

600 s 后中央水量两例同为约 0.164164 kg，未观测区分别约 0.028245、0.116481 kg，相差约 0.088235 kg；接口示例中消费者接收相同的人工观测包并输出未知、授权 false；该接口测试独立于上面的理想状态物理反例。见 `results/witness.json`：`producer_only` 保存真值供验证，不送入 `observe`。此反例说明在所列理想中央状态完全相同、区域独立且其他信息不含未观测区条件下全衣水量不唯一；不证明所有可能的传感或其他观测均不可辨识。真实中央响应和衣物之间的适用性未验证。
