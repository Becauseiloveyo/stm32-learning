# T10 M6：同一动态状态的条件观测与未来情景

本包把历史局部观测、有限候选、M5 状态和未来条件情景连接成可重放的合成研究流程；不是已校准的真实衣物估计、天气预报、概率或收衣判断。所有结果为 `SYNTHETIC_UNCALIBRATED`，seed=null，`collection_authorized=false`。中央对应第一区只是候选中的场景假设，不证明中央最慢；未观测区仅由明确列出的候选表达。

## 输入、时间与证据

`integrated.predict` 只接收 `m6-v1` 请求：`reference_s`、`as_of_s`、截至分析时刻可得的历史分段驱动、M2a 格式的历史观测包与政策、外部传感器初态/接触/热声明、模型和误差声明、有限候选、**事前给出的合成未来情景**、目标和步长。字段严格白名单，额外真值或真实未来字段拒绝；来源方如把事后实况伪装为合法情景，代码无法识别，必须由调用方保证来源。历史分段、候选、初态和假设的 `available_at_s`/签发时刻均不能晚于 `as_of_s`；观测使用 M2a 的采样、收到、证据签发和闭区间覆盖规则，不允许后来的证据回溯成过去在线可得。过去结果不由本包自动持久化；事后在较晚分析时重算是新结果，调用方应保存当时输入与输出。

至少两组历史观测，四通道各自实际采样时刻严格递增、同一安装；最后的外部接触和无已知热干扰声明必须覆盖参考时刻至分析时刻，以覆盖传感器响应历史。缺测、接触未知或未接触、热/初态/历史不足使所有候选信息不足，不产生衣物记录或有效排除。M5 的 RH 响应状态在参考时刻需有外部证据及误差界，不用合成真值代替自动检测。历史空气边界在对应温湿度各自实际采样时刻与其声明误差及合成温度模型误差比较，若不相容，候选保持信息不足；本包不借用 M3 的恒温窗口门控，允许分段动态环境。每个参考状态与其 `prior_drive` 同时给出，M5 空气温度边界为外部假设而非完整热气路证明。

## 同状态筛选与继续推进

每个候选明确给出 M5 两区参数、覆盖与气腔参数、完整八项参考状态的有限离散变体、前一边界、固定偏差区间及声明时间；区域、传感器、气腔水量、累计质量/能量账都在候选状态中，不在观测或预测切换时重置。`complete_discrete_support` 只指本候选列出的有限变体，不证明连续初态已覆盖；不确定或模型/误差声明未知时必须信息不足。M5 参数单位及软件域见 `docs/GARMENT-COUPLED.md`，本包时间 s、RH 比例、温度 °C、水量 kg、能量 J、目标 X kg水/kg干布；每个候选及场景具体合成值见本包 `config.json`。

从参考时刻用 M5 的动态模式积分，按实际 RH 样本时刻及历史边界分段。对候选的每个离散变体，使用同一个固定偏差 b：每个样本允许区间为 `observed−predicted ± (measurement_error + structural_rh + numeric_rh)`，与候选偏差及 M5 初态、RK4 阶段/步末偏置后 RH 域取共同交集；不允许逐样本独立选择偏差。合成误差界和保护带若缺少依据须声明 unknown，不能用来排除真实候选；数值步长加密不是严格误差界。各变体保留 compatible、incompatible、information_insufficient、calculation_failed 或 outside_initial_evidence。任何候选的未解决或失败变体使候选未解决，不以失败冒充排除；全部不相容报 `coverage_or_model_mismatch`，不自动选择最近者。候选不代表现实连续参数全覆盖，结果无概率解释或真实材料识别。

每个兼容变体的**完整 M5 历史末态与末边界**继续到每个单独声明的未来情景，`transition` 处理空气温度改变的水汽能量跳变；参数、区域、气腔水量、传感器响应和累计账不重置，也不调用旧 M2b 代替 M5。未来观测/真实天气不参与历史筛选，改变未来情景不会改变历史相容状态。未来情景的覆盖/接触持续只是条件假设，不表示真实未来接触已确认；不产生干燥记录或真实收衣授权。

## 目标与失败

结果自带 `request_version=m6-v1`、`state_version=m5-v1`、参考/分析时刻、`target_x_kg_kg`、步长及独立复制的 `future_conditions`。因此下游读取结果时能知道时间依赖哪些分段条件；完整候选和历史输入仍须与结果一起保存。协调者在交付停止后补齐这些解释字段，不改变物理方程、筛选和时间数值。

每个未来情景在同一采样时刻检查两个区域都满足 `X≤target_x`；不取各自首次达标的最大值。网格包含分析时刻、每个积分步末和情景分段边界；首次检出 `first_sample_s` 为同一相对时钟中的绝对时刻，`remaining_sample_s=first_sample_s−as_of_s`，初始满足为 0，`previous_sample_s` 为前个网格点。步间短暂共同达标或再湿可能漏检；前一点不构成连续首次穿越的严格包围。继续至时域末标记采样点再湿，不保证以后持续达标或引入固定等待。

未来计算失败/凝露后保留失败原因、最近成功完整状态及其驱动，也保留失败之前已检出的时间和返湿标志；这些组合未解决、整体上界未知。未达到时域终点、历史信息不足/计算失败同样不删除成员来制造有限上界。`upper_sample_s` 与 `upper_remaining_s` 只有在所有尚未排除候选的全部变体/情景均成功检出时才有限；不相容的有限离散点只在所声明的合成条件下排除。没有兼容候选时上界同样未知，不称真实收衣时间。

## 样例、验证与成本

本包的输入保存在 `config.json`：历史参考 0 s、分析 20 s，1 s 步长，目标 X=0.3；两组假设具有不同初始中央及未测区水分，合成局部 RH 读数由隔离的 `producer_fixture.json` 与 `verify_producer.py` 离线复核，**生产者隐藏数据不传给 `predict`**。高/低水量候选相容、低活度候选不相容；两个合成未来情景到 60 s 均未检出，上界未知。样例的误差界、偏差、响应与气路均为人为假设，不代表材料或仪器标定。

每次请求先按候选变体数、历史长度、采样点、每个未来分段/时域和步长估算最大积分步数；上限 200000，超限、步长过小或重复候选/变体/情景 ID 抛错，不能悄悄截断候选。实际 CPU/内存随状态、时域和步数增长；示例估计 318 步，当前本机一次约 0.04 s，非性能承诺。分段边界可能增加网格点，时间仍不声称连续精度。

独立解析退化检查关闭表面交换、换气和热通量，各区线性排液 `X_j=X0_j exp(−k_j t)`：X0=(1.0,0.8)、k=0.001 1/s、目标 0.3，解析共同时间约 1203.97 s；从分析时刻 20 s 用 10 s 网格检出 1210 s（剩余 1190 s）。另以零交换恒定 RH=0.5，观测 0.51/0.53、误差 0.001 验证同一偏差区间互不相交；不是通过同模型拟合自身证明全部物理正确。测试另覆盖已检出后再湿/失败、非重叠达标、动态历史温度切换、分段前后全状态重放、缺测/时序/接触/错误先验/数值失败及隐藏字段隔离。
