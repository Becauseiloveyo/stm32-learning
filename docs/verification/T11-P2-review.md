# T11 P2 独立审查

2026-11-03。接受电脑上的电量调度、预测观测付费和持久消息联动。P1 提供实际事件，M6 在电脑侧运行；电池、网络及天气输入为合成情景，收衣授权为 false。[可复现收据](T11-P2-tests.json) · [实现说明](../T11-P2-TRANSPORT.md)

| 反例 | 核对结果 |
| --- | --- |
| 同一受水事件，不同网络 | 设第 61 秒开始受水，第 62 秒本地检出并持久排队。正常情景第 68 秒到达模拟接收端；断网情景第 82 秒超时、第 142 秒重试、第 148 秒到达。两条运行截至第 62 秒的公开决策轨迹一致 |
| 离线换衣或衣架重启 | 第 73 秒失效。远端第 74 秒查询时仍能看到上次同步的条件预测，第 101 秒查询时已过期。第 148 秒恢复同步后，无旧衣物受水或预测提示 |
| 服务器收到、确认丢失 | 第 68 秒服务已保存并产生一次模拟提示。第 148 秒再收到同一提醒键，当前状态可见，新增提示数为零 |
| 测量进行中发现受水 | 第 27 秒开始测量，第 62 秒取消。已发生的 35 秒测量电耗、5 秒风机和两次风门动作共计负载侧 1.17 J。另一个情景完成 140 秒全程，负载侧为 4.38 J |
| 电量不足、反复插拔 | 从 134.2 J 开始且无人充电时，无线一直遭拒。相同初始电量下，人工充电两段合计输入 35 J，转换后 26.25 J，第 60 秒获准发起连接，第 66 秒完成同步。插拔引起的旧预测不会自行恢复 |
| 样本缺失或上传太晚 | 缺一包的实际 M6 调用返回 unresolved。另一项独立测试中，包在等待上传时超过有效期，系统放弃该计算 |
| 能量边界与上限 | 九组回放逐项对平电池账。满电外接电源时，第 30 秒开风门并立刻取消，两次动作均实际扣费。连续五次失败后，即使网络恢复也不在同一次运行内再次扣无线费 |
| 事务中断与迟到确认 | 子进程分别在事务写新 head 后、提交后直接退出。重开得到完整旧态或完整新态。满队列淘汰数与记录一同提交，旧 ACK 不会清除新条目；冷启动安全状态提交后，迟到旧报文也不复活提示 |

三组测试包括电量 8 项、消息 7 项、协调者联动 9 项，共 24 项。另核对冻结输入与 P1 收据，并从头运行九个情景，将回放与清单逐字节对照。收据绑定 190 个文件，覆盖 P1 已接受的 172 个文件。[回放与输入清单](../../research/integration_t11/p2/results/manifest.json)
