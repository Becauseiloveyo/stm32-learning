## 结构选择的审查原则

| 结构 | 可保留的研究理由 | 目前不能推出的结论 |
|---|---|---|
| O 开放布点 | 用同类探头观察不主动换气时的局部趋势，作为对照 | 没有固定有效体积或关窗过程，不能直接套用腔体恢复窗口证明判干。 |
| C 单面气窗腔体 | 固定部分几何与命令，便于拆分空白、开窗、关窗和装夹因素 | 织物和边缘仍可交换；命令不是流量反馈；强信号仍可能来自腔壁。 |
| B 可拆背片变体 | 在 C 上只改变背侧几何，便于配对考察背侧影响 | 更封闭不是抗风性能证据；背侧可能形成未观测的第二湿空气空间，且改变局部蒸发。 |

优先研究 C 的依据只能是可控制、可比较的条件较明确；保留 O 作对照、B 作可拆变量。不能把这个研究次序称为三结构实际性能排名，也不因此冻结尺寸、材料和器件。

## 独立数学核对

沿用现有近似等温、恒定环境、固定表面势的假设。用 Python Decimal 直接核对两参数组：K＋Q_l 均为 0.04 mL/s，K(a_w−0.6) 均为 0.008 mL/s。因此同样已知的 Q_u(t) 不能单独消除该反例。这是模型内不可区分性，不是实际衣物状态的标注。

覆盖反例用每面 KQ/(K＋Q) 的两面和分别除以未限制参考，独立算得 0.7625、0.3675，与预研一致。这只能说明在假设下减小气体交换可同时减小瞬时通量，不能转成实际背片对干燥速度的百分比，也不能取倒数预测时间。

## 必须保留的未知量

- 漏风：需要实际装夹、工作压差与风环境下的独立气路证据。同一湿度曲线同时拟合 Q_l 和表面状态，不构成独立约束；气窗位置反馈也不能独自证明流量。
- 壁源：需要有预湿历史的空白及材料对照；用不透气片替换织物会改变通路，不能直接无条件扣除空白。
- 覆盖与代表性：需要覆盖／未覆盖、主动／被动及重夹对照，并另有独立衣物参考。局部测点不能代表未观测到的衣兜、裤腰和厚缝。
- 拉动与滑移：开夹事件只能提供部分安装信息；未触发开关的滑移仍可能改变间隙和漏风，不能凭协议完整宣称已排除。

若这些约束仍不足，应保留局部水汽趋势和“未确认”输出，缩小安装／使用范围；不靠调整演示门限或累计次数强行授权收衣。
