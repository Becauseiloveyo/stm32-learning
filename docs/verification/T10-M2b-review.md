## 预先确定的审查重点

- 参数/初态是计算端明确提供的合成先验，不读取生成器真值、材料标签或实际未来天气。未实现观测映射时保持 scenario_only / observation_mapping_unavailable。
- 对两个建模区域的目标必须检查同一时刻共同满足。再湿时，不能用各区首次穿越时间的最大值代替共同达标时刻。
- 不删除未达标、出域、积分失败的成员后制造有限上界；说明已达目标样本的范围与整体仍未知的范围。目标与含水量单位、未来时域、环境切换时刻和成员来源必须可追溯。
- 固定步长得到的是网格检出；没有额外论证时不把一个步长当连续首次穿越误差的严格上界，不保证没有漏检步间短暂变化。首次达到与以后持续满足分开。
- 同一 M1 方程的另一数值方法只能验证数值一致性；实际衣物参数、收衣端点、传感器映射仍未标定。

## 独立参考的推导

将蒸发、太阳、对流和长波面积设为零，保持液水温度与初始织物温度一致，退化为单区线性质量平衡：

`dX/dt = R/m_d - kX`，`Xeq=R/(m_d k)`，`X(t)=Xeq+(X0-Xeq)exp(-kt)`，温度不变。

当 X0>Xgoal>Xeq 时，解析穿越时间为 `ln[(X0-Xeq)/(Xgoal-Xeq)]/k`；若 Xgoal≤Xeq 且 X0>Xeq，正时间内不穿越。无雨是 Xeq=0 的特例。两区均单调下降且分别有限到达时，共同达到时间才等于各区解析时间的最大值。

再湿参考可用分段常量 R 的同一解析解逐段衔接；构造一区先达到后再湿、另一区较晚达到，检验各区单独到达与共同达到的区别。所有几何、k 和水量均明确合成，不称真实织物实验。
