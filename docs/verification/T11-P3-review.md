# T11 总体离线审查

本轮交付[晾衣观察室](../demo/hanger.html)。衣架状态来自 P1、P2 和电脑侧 M6 的实际执行，每条情景独立建库回放，均为合成输入。收衣授权为 false，真实手机送达为未知。

| 范围 | 检查依据 |
| --- | --- |
| 事件和失效生命周期 | [P1 审查](T11-P1-review.md)覆盖预报、本地受水、身份域、过期以及观测与计算。 |
| 定时能耗与持久投递 | [P2 审查](T11-P2-review.md)覆盖低电准入、人工充电、超时、确认、满队列和中断恢复。 |
| 界面投影 | 九个原 P2 情景沿用既有输入，逐秒运行后核对每项日志动作。补充七个情景验证预报离线生效与过期、预报与探头读数不一致、中央未接触、历史满队列、模型失配、设备故障及探头遮挡。每个可选择的关键帧独立呈现当前证据。 |
| 交互与显示 | 浏览器遍历 16 个情景、264 帧，核对每帧本地与远端的数值有无、历史计数与新增提示。对选定帧独立断言具体内容、原时刻与失效后的下一帧。上一帧、下一帧、键盘及四种窗口宽度通过检查。桌面与窄屏截图已逐张查看。[浏览器脚本](../../research/integration_t11/p3/browser_review.js) |
| 资源与后续验证 | 提供 RAM、持久存储及回收条件的[可复算示例](../T11-RESOURCE-REVIEW.md)。与既有 C 主机数据分列，尚无 MCU 目标编译或实测。 |

生成器重跑后 HTML 与来源清单字节一致。Playwright 在本机临时回环地址核对界面；另用浏览器直接打开本地 HTML，核对默认帧的实际 DOM。源码、产物、截图与前序收据由[本包收据](T11-P3-tests.json)绑定。[完整验收矩阵](../T11-ACCEPTANCE-MATRIX.md)

T11 的接受范围是课程设计的电脑离线联动。对相同探头输入不能判别雨、露或喷溅，单中央观测也不能证明整件衣物已干；时间与能耗依赖合成参数。浏览器宽度验证不代表实体手机推送或兼容性测试。下一项 T08 对照全部用户要求、预算和未测条件整理理论阶段评审及最小实验清单。
