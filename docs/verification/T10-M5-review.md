# T10 M5 动态衣物与中央气路协调审查

2026-11-01。**接受 M5 两区衣物动态状态与中央覆盖气路的统一前向原型**，范围限定为给定局部空气温度和合成 RH 响应。没有完整湿空气/壁体热闭合、真实参数标定或观测更新到整衣 ETA；T10 仍在进行。

## 重点

- 同一衣物库存中分开开放与覆盖流量；内部覆盖水流在空气与衣物中抵消，热量采用同一参考焓，不重复扣蒸发潜热。
- 两计算区与中央位置的映射是情景声明，不把中央当成所有衣物的慢干位置，也不从未测区域取得伪观测。
- 衣物温度随物理驱动推进；局部空气/壁的储热、边界、外部热库或忽略项须说明。总账通过不能自动证明实物模型适用。
- 非等温传感器状态有明确物理含义。环境切换时质量、衣物储热和响应历史不能意外重置；规定温度的跃变若改变所计储热，必须有明确跳变账。
- 凝露/非法输入/积分越域暂停，不把裁剪后的轨迹用于预测。分段边界前后所用驱动和观测时刻一致。
- 退化参考独立推导；旧 M1/M3 对照仅证明匹配条件下的一致性，不能算真实实验或独立参数校准。

## 预备解析参考

关闭蒸发、覆盖、日照和辐射，仅保留同温排液及常温空气的显热交换。若排液也关闭，衣物热容 C 恒定，换热导纳 K 恒定，则 `T(t)=Ta+(T0-Ta)exp(-Kt/C)`，`U=C*T`。只用恒定吸收日照功率 P、其余热流关闭时，`T(t)=T0+Pt/C`。这些是隔离方程项的人工退化例。

关闭所有表面通量，只留同温液水输入 R 与线性排液 k*w，则 `w(t)=R/k+(w0-R/k)exp(-kt)`，温度保持初始液水温度；k=0 时是 w0+Rt。质量/变热容显热账须同时符合。

局部空气无覆盖交换、恒定容积及固定温度时，换气导致 `rho(t)=rho_a+(rho0-rho_a)exp(-Qt/V)`。局部 RH 恒定时，一阶 RH 响应是 `z(t)=RH+(z0-RH)exp(-t/tau)`；非等温时只有在具体传感模型定义后才能使用相应参考。

## 给定局部空气温度的条件账

实际实现选择水汽比内能 `uv(T)=hv(T)-Rv(T+273.15)`，用 `m*uv(Tc)` 作为固定体积水汽储能；不是直接把流动比焓当作储能。固定温度段，外部补偿为 `G=uv(Tc)*(Mc+Mv)-Mc*hv(Tf)-Mv*hv(Tc)`，Mv 为换气净水流。环境温度跃变时，单列 `m*(cpv-Rv)*(Tc_after-Tc_before)`。M1 中 CV 的数值在这里用作 cpv；符号同时覆盖蒸发和吸湿。

这是所选水汽控制体与外部边界的账，不是包含干空气、腔壁和压力功的完整气体热模型。不能在已扣完整蒸汽焓后又重复扣同一潜热；也不能用这份账证明真实被动气腔满足所给温度。
