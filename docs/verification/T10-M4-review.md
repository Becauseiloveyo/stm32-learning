# T10 M4 候选相容性协调审查

2026-10-30。**接受 M4 有限离散候选在明确合成模型与误差声明下的相容性原型**。没有完成真实材料识别、概率校准、连续参数完备包络或整衣时间观测校正；T10 仍在进行。

## 预先确定的检查

- 消费端只读当前可得观测、外部声明与公开候选；生成器真值和未来环境不能决定筛选结果。
- 仅在固定温度等模型前提与误差条件明确的合成子域筛选。缺失证据、未建模作用、积分失败均不能冒充观测排除。
- 有限候选的相容子集不代表连续参数全覆盖。持久偏差和初始响应状态跨整个窗口保持一致；逐时刻任选参数不是同一个候选。
- 用实际采样时刻推进；过去时刻不能用后来签发的声明。当前时刻允许的历史重算须清楚标明。
- 未知、计算失败和全部不相容要保留，不能选最近者或输出虚假的确定水量范围。
- M3 局部模型与 M1/M2b 的热边界及区域尚未统一，不能在此包宣称整衣观测修正 ETA。

## 独立数学参考

令候选无偏输出为 f_i，观测为 y_i，逐点误差限为 e_i，共用恒定偏差 b 属于 B。全部样本相容的必要且充分条件（针对这个加性误差子问题）是：

`B ∩ intersection_i [y_i-f_i-e_i, y_i-f_i+e_i]` 非空。

例：f=[0.5,0.5]，y=[0.52,0.48]，e=0.005，B=[-0.03,0.03]。每个样本单独可调偏差拟合，但两样本所需偏差分别在 [0.015,0.025] 和 [-0.025,-0.015]，交集为空。相反 y=[0.52,0.52] 的共同交集为 [0.015,0.025]。若实现采用逐候选固定偏差，只验证该固定值，不冒充求出连续交集。

无覆盖、无开放面积、无壁源且 Q=0 时，局部空气 RH 恒定 r，传感器输出 `f(t)=r+(z0-r)exp(-t/tau)+b`。可在非整步长时刻构造观测，独立验证时间推进、响应初态、偏差与误差边界；此退化例不需要调用生成器获得解析观测。
