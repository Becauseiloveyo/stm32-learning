# T12：衣架布局与人工充电研究

全部尺寸、装配净空、电池及工作量为 `DESIGN_ASSUMPTIONS_NOT_MEASURED`，seed=null；这是电脑上的几何与能量比较，不是可制造图纸、器件选型、实测续航或收衣授权。`collection_authorized=false`。本包不采购、不部署、不设计太阳能供电；衣物日照和电池充电分开。

## 坐标、几何与失败例

`research/hanger_layout/config.json` 使用 mm，x 为衣架横向，y 向上，z 为衣架前后深度；所有实体和空间是 `[xmin,ymin,zmin,xmax,ymax,zmax]` 轴对齐包围盒。严格正体积相交才报碰撞；边界恰好接触按无体积重叠处理，不等于真实留有公差。钩口和衣领为操作净空代理，并非真实钩子的完整三维曲面；相邻衣架代理沿 +z 深度放置，示例深度 35–65 mm。尺寸与坐标均为人为场景，容量不推算电池几何。

检查全部列出的主机、电池、横杆、中央探头、参考探头、雨头、充电口、衣物代理之间的非预期体积相交；明确例外仅为充电口嵌入主机、中央探头与衣物代理的预期重合。钩口/衣领空间均检查主机和电池；邻架代理检查主机、电池及三个探头；参考通风、雨头上方暴露、插头插拔净空与其他实体及给定遮挡盒碰撞检查。中央接触代理要求中央探头、目标区和衣物代理三者有共同正体积交集；它只是占位关系，不证明真实接触、压力或干湿测量。中央探头外包络/接触代理面积不是 M5 中的有效覆盖面积，**不自动修改 M5 参数**。

## 电池与工作量

示例额定电池 0.25/0.5/1.0 Ah，3.7 V，可用比例 0.8，起始满可用电量，5% 可用能量作为动作预留；均是设计假设。电池侧可用能量 `Ah×V×0.8×3600` J，分别 0.74/1.48/2.96 Wh，**不与任一电池体积绑定**。基线 0.2 mW 为负载侧，负载转电池效率假设 0.85；动作增量同属负载侧，统一除 0.85 一次。普通测量 0.02 J/次，主动测量周期 4.38 J/次为 T09 的主动增量；本包的“增加主动测量”仅排主动周期，普通测量次数设为零，并不声称主动周期包含普通测量。若两种动作都发生，须分别调度并各计一次；Wi-Fi 示例 0.6 W×8 s=4.8 J/次，弱网采用 12 J/次，均是假设而非实测。

| 人工工作量 | 负载调度假设 | 请求的电池侧日能量 |
|---|---|---:|
| 普通 | 每 900 s 普通测量，每 21600 s 一次联网 | 约 45.18 J/日 |
| 弱网 | 每 900 s 普通测量，每 7200 s 一次较贵联网 | 192 J/日 |
| 增加主动测量 | 每 900 s 主动周期，每 21600 s 联网 | 537.6 J/日 |

本包工作量没有加入 T09 的 0.004 Wh/日杂项或 1.25 预算系数，数值不能与 T09 总额直接等同。日预算 `可用初值−请求日能量×天数` 是**需求裕量**，不是实际执行消耗；实际时序在能量不足时会跳过动作或产生基线缺口。27 组（3 容量×3 工作量×7/14/30 日）的请求裕量、实际消耗、动作成功/跳过及基线缺口见 `results/analysis.json`。例如 30 日、0.25 Ah 普通组没有模型内服务缺口；0.25 Ah 弱网有 1807 次动作跳过及约 206.47 J 基线缺口；1 Ah 增加主动测量有 1117 次动作跳过。这只在给定电压、效率、工作量恒定的情景成立，不承诺实际续航。

上述定时联网次数只是预算情景，**没有自动包含所有雨情/干燥事件通知**。版本化 T11 契约允许通过显式 `event_actions` 传入事件时刻和负载侧 J；示例事件 Wi-Fi 4.8 J 是相同的合成负载，不保证重试或送达。PC 上的 M6 集合推演不算入 MCU 电池负载。

## 人工充电与充电口

无外接充电时输入为零，日照不向电池充电。外部电源事件采用 `[start_s,end_s)`，输入侧功率乘充电效率得到可供电池路径的功率；同时运行的负载按单次转换效率折到电池侧。满容量外的能量记 `curtailed_j`，不能借用尚未来到的充电能量。累计满足 `末电量=初电量+充电效率后能量−弃充−已供基线−已执行动作`；不足预留的动作跳过，基线耗尽量另计。`results/analysis.json` 包含 3600–5400 s、1 W 外部输入/0.75 效率的满电与空电两例及逐事件 trace（含满电/耗尽时刻、动作准入及拔线后区间）。空电示例的第一次普通测量在 900 s 被拒，不能提前借用 3600 s 之后的充电。满电输入经效率后 1350 J，其中约 1348.61 J 因饱和被弃；这不是充入电池的能量。

位置示意：左侧案充电口向 −x、右上案向 +x；是否存在插头/手指实际空间以几何与未来操作验证为准。**只考虑充电口防水**：闭盖状态表示假设盖合、未验证密封；开盖时提供插拔净空；充电时外部连接已声明且热干扰可能存在；拔出后输入在结束时刻停止，热恢复时间未知。没有自动端口湿润检测，充电口状态/受水不能靠软件伪造为已知。未来验证应分别检查盖合与开盖时的合理暴露、受水后的处理、反复开合/插拔磨损及插头遮挡；不声明 IP 等级或通过防护。

T11 机器接口为 [t11-interface.json](../research/hanger_layout/results/t11-interface.json)，版本 `t11-power-1.0`；包括基线和动作的负载侧与转换、容量、预留、外部充电输入、事件通知、充电热未知及失败含义。峰值电流、压降、充电 CC/CV、温度/老化容量曲线、恢复时长及目标 RAM 均未知。平均 Wh 不能证明峰值供电、射频或实际充电安全。
