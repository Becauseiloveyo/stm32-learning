# T10 M5：两区衣物与中央空气的动态前向模型

本包为 `SYNTHETIC_UNCALIBRATED` 合成前向研究，seed=null、`collection_authorized=false`；不是经过实测的整衣预测器、接触检测器或 ETA。两计算区与中央位置的对应仅为情景假设：本包约定第一区有中央覆盖，另一区不被局部测量；不能据此断言中央一定最慢。没有采购、设备部署或新增加热器。

## 状态及不重叠面积

衣物区 j 的干质量 md kg、库存 w kg，`X=w/md` kg/kg，衣物参考显热 `U=(md cd+w cw)T` J，0°C 的干布和液态水为零。气腔状态为水汽质量 m kg，体积 V m³、密度 ρc=m/V kg/m³；气腔温度规定为外部环境温度 Ta（°C），不是由气腔热模型算出的温度。空气参考 ρa=RH_a·ρsat(Ta)。传感器状态 z 是 **RH 比例的一阶响应状态**，输出 z+b，`z'=(ρc/ρsat(Ta)−z)/τ`；τ 和偏差 b 均为手选合成参数。它假设传感器敏感元件温度立刻等于 Ta、响应对 RH 而非水汽密度一阶滞后，不声称真实传感器或安装满足；温度跃变时 RH 目标可突变，但 z 不重置。这不是把 M3 的密度响应状态除以新的饱和密度而当成实际 RH 动态。

两区总蒸发表面积分别 Ae0、Ae1，第一区拆成 Ac（覆盖）及 Ae0−Ac（开放），第二区 Ae1 全开放，约束 0≤Ac≤Ae0。`aw=1−exp(−w/(md Xb))`，Ro 是合成阻力 r0/(1+v)，Rc 为覆盖阻力：

```text
Mo_j = Aopen_j/Ro_j · (aw_j ρsat(Tj) − ρa)
Mc   = Ac/Rc · (aw_0 ρsat(T0) − ρc)
V_j  = Mo_j + (Mc if j=0 else 0)
D_j  = k_j w_j
w'_j = −V_j + R_j − D_j
m'   = Mc + Q(ρa−ρc)
```

Mo、Mc、R、D 单位 kg/s，Q 为 m³/s；气腔壁源为本包零假设（未知不等同于现实中零），不模拟有限壁库存。正蒸发、负吸湿均保留；覆盖 Mc 在衣物和腔体等量异号，只扣一次。受限接口沿用单个 `Drive`，人为给定的 `rain_kg_s` 对两区**各自**赋同一 R，D 为各区参数 k·w；这不是从二值雨头推算的衣物吸水量，不代表真实截获分布。第一区覆盖仍沿用 M1 的全部对流、辐射、太阳有效面积，这是合成假设，实际遮挡/夹持未建模。

## 能量基准与外部边界

M1 的水汽比焓 `hv(T)=L0+cpv T`，L0=2.5e6 J/kg、cpv=1850 J/(kg K)（M1 变量名 CV 在此用作水汽定压比热近似）。液水焓 `hl(T)=cw T`，cw=4180 J/(kg K)：

```text
U'_j = Qsolar_j + Qconv_j + Qrad_j − V_j hv(Tj)
       + R_j hl(Train) − D_j hl(Tj)
```

衣物的热流使用合成 M1 对流/辐射闭合。空气中的水汽采用理想气体的参考比内能 `uv(T)=hv(T)−Rv(T+273.15)`，Rv=461.5 J/(kg K)；气腔水汽储能 `Eg=m uv(Ta)`。气腔固定体积但 Ta 由外部强制，干空气储热、壁体热容、真实压力场/湿空气流动和压力功未作为状态闭合；外部热库边界承担这些理想化差额，**不是对被动衣架热平衡的证明**。分段内设气腔通风净水流 `Mv=Q(ρa−ρc)`，保持其 Ta 所需的水汽边界补偿为：

`G = uv(Ta)(Mc+Mv) − Mc hv(T0) − Mv hv(Ta)`。

它对应水汽控制体内能变化减流入/流出焓；吸湿用同一有符号通量及衣物表面温度焓近似，忽略吸附热、流入蒸汽的独立温度过程。若气腔和覆盖温度不相同，外部边界须补偿差额，尚无真实结构依据。与衣物相加时 Mc hv(T0) 等量反向抵消，**外部能量账**直接分项为：

`Σ(Qsolar+Qconv+Qrad) − Σ Mo_j hv(Tj) + Mv hv(Ta) + Σ[R_j hl(Train)−D_j hl(Tj)] + G`。

液水带走/输入的焓与库存变化对应；本接口无其他水源。输出 `boundary_integrals` 分项为 J 或 kg，另有独立端点梯形数值积分类别；不能仅以同一状态 RHS 的和冒充独立物理边界。`clamped=True` 仅为显式 **bool** 的验证模式：衣物温度由额外外部虚拟热库约束不变，所需补偿单列 `clamp_reservoir_J`；正常模式为 `dynamic`，不暗示设备配备热源。

## 分段推进与域

`run_segments(zones,c,y,segments,dt,prior_drive)` 从调用者给定参考状态和前一外部边界开始，分段结束时间为距该参考时刻的秒数且严格递增。y 的八项依次为 `[w0,U0,w1,U1,m,z,累计外部水量,累计外部能量]`，units kg/J/kg/J/kg/RH比例/kg/J；输出版本 `m5-v1`、起始/结束驱动、完整末态与分段账。后续窗口须携带**相同区域/耦合参数、完整末态及结束驱动**，以结束驱动作为下次 prior_drive；本包未做持久化、身份或跨版本验证，调用者负责。直接调用底层 `integrate` 时，状态必须已与所传边界匹配；不要跳过 `transition`。

温度边界从旧 Ta 突变到新 Ta 时，水量、两区显热、气腔质量和响应 z 连续；气腔水汽内能因外部强制温度产生跳变量 `ΔEg=m(cpv−Rv)ΔTa`，加入外部能量账并单列 `boundary_jump_j`。它不覆盖干空气与壁面温度跃变的实际热量。新边界下超出饱和或其他域时拒绝，不裁剪；本包不处理凝露。环境变化分段可改变日照、风、Ta 和 RH，状态不重置。

约束沿用 M1 的 X 0–5、空气/衣物/辐射/雨水温度 0–50°C、RH 0–1、风 0–10 m/s、辐照 0–1200 W/m² 和雨水 0–0.01 kg/s 的研究软件域；还要求气腔密度不超过 Ta 饱和密度、z 及 z+b 均在 0–1、正体积/阻力/响应时间。积分中间状态越域直接失败；不等于物理事件定位。无噪声、覆盖阻力、面积、换气、温度响应均合成，未知不等于零。
