## 接口与一致性域

核心不含设备驱动、模型 simulate、默认物理参数或调用方预判状态。调用方提供实际 `hm_protocol`、`hm_gates`、`hs_policy`；全部参数逐项比较并复制为当前配置，事件不能用任意字符串掩盖门限／策略改变。配置变化需要重新安装，历史预约窗口保留至新 boot。观测中的协议身份同样绑定实际协议快照。

单位为秒、摄氏度、百分比 RH、Pa；温度适用域 0–50 °C，RH 0–100%，闭区间。IEEE 754 binary64、round-to-nearest、禁止 fast-math、关闭乘加收缩是已验证算术条件。非 nearest 模式显式拒绝配置／状态事件，不默默计算。输入输出必须有有效长度、完整初始化、合法指针和不重叠的可变存储；核心不保留输入指针。

`hm_assess` 返回 `HM_OK` 只表示完成判定，结果仍可能为 UNKNOWN；配置／数量错误分别为 `HM_CONFIG_ERROR`／`HM_CAPACITY_ERROR`。`hs_handle` 返回 1 只表示输出已填充，业务是否接纳必须读取 `accepted`、`disposition`、`reason`。所有路径的 `collection_authorized` 为 0。

观测 presence 掩码记录 11 个必需键；事件 presence 掩码记录 13 个消费字段。缺失必需字段在核心检查；非数值、NaN、Inf 经适配器表示为 NaN，非法布尔类型表示为 -1，不能把字符串／数字布尔转换成有效传感器值。无符号配置计数先检查 Python 类型及 0..2**32-1，再送 ctypes；`2**32+3`、负数、bool、float 等不会取模。超出 C 支持容量的合法 uint32 继续由 C 拒绝。对 configure 的不可表示新配置，桥接为明确无效配置，进入 FAULT。

主机桥接注册经过 Python 配置解析的真实快照，以当前参考 SHA 查找快照；未知 SHA 变成 NULL。注册不是判定：C 始终接收原始观测并自行计算。未来传输层必须自行校验配置入口／单位、真实传感器来源、启动唯一性及消息认证，不能任意重新绑定 SHA 与参数。

支持域与 Python 的明确差异：

| 项目 | C 限制／行为 |
|---|---|
| 单周期观测 | 最多 512 行；超限在解引用前拒绝，状态机路径锁存容量故障 |
| 协议 | 周期总长 ≤86400 s；采样间隔 ≥0.001 s；标称采样数 ≤512；最小阶段／窗口样本数为 2..512；其余协议验证沿用 Python |
| 策略 | 正时长 ≤1e9 s；复核周期数为 1..16；保留全部原有关系／容差检查 |
| 事件时间／导出 deadline | 有限且在 0..1e9 s；到达上界可作 boot，超过上界或不能表示完整 deadline 明确失败 |
| ID | 1..32 个可打印 ASCII 字节，无首尾空格，33 字节含终止符；超长／Unicode 明确拒绝，不截断。Python 原域为 128 字符 |
| 动态表示 | 采用类型化字段；1 与 1.0、正负零、不同非法数值被规范化；不承诺保持原 JSON 拼写层面的收据区别 |
| 历史存储 | 有界且不淘汰，详见下节；PC 原型的无限历史不在此支持域内 |

对照覆盖关键状态、accepted、disposition、状态原因、测量原因位集合、弱计数、复核标志、身份列表、pending 的身份及三时刻、四个可选时钟、全部配置参数、数值特征及授权标志。时钟要求精确相等，状态／门限分支不使用容差。C 不返回 SHA 字符串和 Python 的长原因文本；前者用实际参数逐项核对，后者用状态原因枚举＋测量原因位核对，未比较原因字符串顺序。已验证的 ID／配置／数据域内正常及保存事件输出一致；这不是对任意 Python 对象、原 JSON 字节或任意数学库的全域等价证明。

## 历史容量、掉电职责与内存

| 固定容量 | 条数 | 本机数组字节 |
|---|---:|---:|
| 消息收据：boot ID＋event ID＋32 字节摘要 | 64 | 6272 |
| 当前 boot 的周期 ID | 16 | 528 |
| 已见 boot ID | 8 | 264 |
| 当前 boot 的安装 ID | 32 | 1056 |
| 当前 boot 的退役批次 ID | 16 | 528 |
| 当前弱证据 ID（含在 snapshot） | 16 | 528 |

容量恰满仍允许已登记消息的精确重复，下一条需要新存储的记录触发 `HS_CAPACITY_EXHAUSTED`：清弱证据及 pending、进入 FAULT、锁存；之后 boot／recover／configure 也不能解除。外来身份及旧启动拒绝不污染当前时钟或链；不得通过驱逐旧 ID 继续计数。每种历史的恰满／超限已验证，最大弱链为 16，继续 200 次尝试也不会增长、溢出或解锁。

新 boot 事件清掉本启动域的周期／安装／退役批次及弱链，保留全进程消息收据与已见 boot 历史。真正 `hs_init` 则重新初始化整个对象，弱计数归零，不恢复旧证据。**调用方必须在真正初始化后保证全新可信启动身份**；本实现没有非易失存储、单调启动计数、掉电原子提交、认证或长期 ID 回收协议。不能把反复 init 当成安全绕过容量的方法，也不声称这一小容量研究原型可长期运行。

GCC x86_64 Windows 本机 `sizeof`：`hs_machine=9616`、`hm_observation=80`、`hs_event=240`、`hs_output=1000`、`hs_config=192`、`hm_protocol=80`、`hm_result=32`、`hs_snapshot=744`、`hs_receipt=98` 字节。512 行调用方原始观测缓冲为 **40960 字节**；它不包含在状态对象中，但计算时必须可用，不能只报状态对象内存。

核心无 malloc/realloc/calloc、VLA 或递归，编译对象未定义符号中也无分配器引用。`.su` 全为 static：`hs_handle=384`、`hm_assess=912`、`hm_mean=224`、SHA 压缩函数 480 字节。精确累加使用两个固定 288 字节累加器，均值函数另有固定 144 字节整数工作数组；编译器帧数已包含这些局部变量。把两个核心编译单元的全部局部函数帧相加得到 **3088 字节**，可作无递归本地函数的宽松预算，绝不是实测调用栈峰值；它不含调用者、桥接、libm／CRT、异常／中断或目标 ABI 开销。ARM 栈、Flash、执行时长和库行为均未测，不能推断具体 STM32 的适配性。

## 数值反例、修复与当前证据

首次 long double 累加方案在 ctypes 宿主中出现门限翻转。可复现输入：默认协议，环境／局部温度 0 °C，环境 50% RH，局部在 time≤55 s 时 50%，之后 60%；Python 的 rise 与 tail 都为 `61.093999999999994` Pa。把 strong 门限设为相邻的 `61.094` Pa、weak=0，Python 为 UNKNOWN，旧 C 算得 `61.09400000000001` Pa 并进入强信号分支。初版一般向量最大差为约 2.73e-12 Pa，仍足以跨过精确门限；因此不能只放宽数值比较。

修复保留原门限和包含边界规则，替换均值算法：把每个已计算 binary64 差分精确解码为以 2^-1074 为单位的整数，正负各 36 个 uint32 limb，先精确相消，再整除样本数并按余数／低位一次 round-to-nearest-even。在温度／RH 有效域内单项绝对值 <2^14 Pa（50 °C 饱和分压约 12360.58 Pa），512 项总和远小于 1152 位容限。它避免 long double 受宿主 FPU 精度影响，也避免先把总和舍入再除样本数的双舍入。未修改 Python，未添加门限不确定带，未跳过反例。

当前额外检验 249 组精确均值，含 512 项正负极值、抵消、跨指数随机数、最小次正规数和半值舍入；逐项与当前 `statistics.mean` 的有理数结果精确一致。均值随机种子 20261027。测量门限测试包含 0、1.234、10、23.456、37、49、50 °C 的精确边界及相邻可表示门限。

最终 **18329 条断言通过**，并非 18329 个独立情景：

- 287 组原始观测：12 个既有默认情景、两种非默认协议的既有无事件情景、缺失字段、非法 flags／类型、NaN／Inf、越界、阶段／时序／间隔／窗口、温差／湿变／开夹、环境与特征精确门限、512 行整数／小数采样边界及带种子的原始随机输入。标称数量按已校验网格的 round(total/period) 计算，避免 511.00000000000006 一类浮点商误拒合法的 512 行协议。
- 已保存 T04 的 **19 个情景、156 条事件**完整重放；加独立边界、配置、重复冲突、诊断伪造、超时、空闲／pending、旧 ID、缺字段等，共 **320 条参考事件**，逐条调用当前真正 Python StateMachine 比较。
- 五类容量的恰满／超限与锁存、16 次弱证据、超长／Unicode／含内嵌 NUL 的 ID、1e9 s 时间边界及超限 deadline、513 行观测、配置计数绕回反例、实际参数变更、非 nearest 舍入模式、SHA-256 已知消息与 hashlib 对照、对象前后 guard 字节。主机 ID 先检查完整字符串，再写 C 缓冲，禁止内嵌 NUL 截出一个貌似有效的前缀。

当前特征最大绝对差 **0.0 Pa**。验证器仍保留 1e-10 Pa 的数值比较预算，约为最大水汽压范围内几十个 binary64 ULP，用于报告有限精度差；它从不修改业务门限，也不能掩盖分类差异（分类始终精确比较）。本机向量相等不保证其他平台 exp／编译优化也相等；换工具链／目标必须重新跑原始门限向量，出现分支差异不能只调比较容差。模拟种子 20261023，随机观测种子 20261026；完整参考配置、协议变体、模拟参数及 14 个输入／源码 SHA-256 均在角色结果 JSON。
