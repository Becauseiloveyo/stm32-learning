## 建议分派步骤与文件边界

1. **契约与闭合**：在 `research/garment_prediction/` 建配置及来源清单，明确两区 `X` kg/kg、`T` °C、干质量 kg、面积 m²、时间 s、辐照 W/m²、水流 kg/s、能量 W；逐项记录有效范围、假设/文献来源、合成种子、端点和单位换算。未知材料及局部风/日照采用区间；不把格点风当衣物现场风。冻结版 0–50°C 为研究范围，环境及织物温度分别检查。
2. **独立开放织物基线**：实现两区质量和能量方程及明确合成闭合函数；无约束跨区迁移先不加入。正负水汽通量分别处理蒸发和吸湿，零库存事件定位、防负库存并报告守恒残差；排液及雨水的质量、焓与假设一致。日照投影面积不等于蒸发面积。
3. **数值验证**：固定可重放输入，检查各步和累计质量/能量账；比较至少两种步长并与独立方法/求解器比较，记录容差、尺度和事件处理。无确定容差前先做解析极限和收敛趋势，不能凭一个任意固定阈值声称准确。
4. **观测适配与集合**：原短窗口模块只读；定义温度、时序、安装身份及有效条件，先离线映射，超出近等温条件即不适用。覆盖区与开放区质量/潜热只记一次。生成器与估计器接口隔离：估计器只接观测和事先允许的先验，不读取隐藏状态、真实参数、情景名称或未来实况。按安装变化/异常重置或暂停；单点未约束慢区时标记局部或模型外推。
5. **条件时间与挑战集**：以合成目标为端点，最慢区首次达到目标作为成员时间；未知/超出时域保留，不能用数值上界代替。使用持续、日照降低/高湿、通风改善等未来情景，记录预报签发时间、位置和有效期；实际未来天气仅可隔离为预知上界。以不同参数族和扰动生成挑战；比较固定时间、单湿度阈值、被动差分及集合基线，报告合成提前判断、覆盖、拒判、等待和能量（如能量未建模则注明不可比较）。
6. 交付独立重放脚本、配置/来源、结果及 manifest、独立验收收据和 `docs/GARMENT-PREDICTION.md`；不改 C 固件、T07 消息类型及既有模型。协调者检查依赖后才更新状态，后续雨情/通知集成另作任务。

## 验收矩阵

| 项目 | 最低证据与失败处理 |
|---|---|
| 状态、来源 | 配置完整、单位转换和合法域测试；来源、假设、种子、目标与输入哈希可追溯；缺失关键环境温湿度暂停有效预测。 |
| 守恒与边界 | 两区及总量残差随步长收敛；平衡、蒸发冷却、吸湿、排液、零库存有独立期望；不能静默截负或掩盖残差。 |
| 求解可信度 | 多步长与独立积分对照覆盖事件及驱动突变；残差或差异不收敛则停止，查明数值或物理闭合。 |
| 超域 | 环境或织物温度超范围、无效 RH/参数、缺失必要驱动明确拒绝/暂停；不得裁剪后当有效全年预测。 |
| 不确定性 | 薄区/慢区、未知及误选面料、初值/风/衣物日照区间、雨后再湿；同观测不同隐藏水量和剩余时间反例不得被虚假收窄。 |
| 隔离 | 估计输入清单和自动测试证明隐藏真值、场景名、未来实况不可达；天气预知对照独立标记；挑战集改变生成族。 |
| 观测 | 温度转换、覆盖面积和质量账一致；安装变更、缺测、环境参考污染/局部遮挡明确降级；单点不得宣称整衣已观测。 |
| 输出 | 版本、参数来源、计算/观测时间、未来假设、范围、时域、未知原因及 `SYNTHETIC_UNCALIBRATED` 可重放；非概率集合不得称置信区间；`collection_authorized=false` 包括 ETA 为零。 |

## 阻碍与停止条件

- 水活度与内部阻力均未知且互相混淆；只能先固定合成函数族并保留区间，不能由一条曲线推断真实面料或唯一参数。
- 变水量热容、潜热、雨水/排液焓及零库存事件的离散账必须闭合；若独立求解和守恒检查冲突，暂停扩展估计器。
- 局部腔体等温密度/分压换算及覆盖面积的耦合缺少热闭合；不满足适配假设时标不适用，不以整衣开放蒸发重复扣水。
- 单点局部曲线难辨慢区、初值和漏风；缺少独立标定时保持宽范围或拒判，不生成实物收衣授权。
- 天气时序和衣物现场输入不等同：预报签发/观测时刻不可混入未来实况；缺测或不可信风、遮挡及日照需情景化，不得伪造精确值。

本报告未运行新的仿真或数值测试；上述是未来验收设计，不是通过证据，也不代表实物准确率、概率、可部署性或真实收衣能力。建议协调者先冻结无光伏的新依赖和安装/观测语义，再按步骤分派 T10；保持当前规划工作与下一实现任务分开。
