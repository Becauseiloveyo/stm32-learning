# T10 M5：统一整衣动态温度与中央观测的前向模型

2026-10-30 编制。沿用专用 Terra 算法对话；此任务书不自动启动，STATUS 记录实际派发。目的为补齐原 T10 的动态物理连接，不新增产品功能或测点。

## 最小输入与所有权

读 AGENTS、PROJECT、STATUS、TEAM、本任务书、M4/M3 协调审查和 GARMENT-ENSEMBLE 的连接缺口；只按需要读 M1 方程/参数、M3 物理及 M2b 目标时刻契约。恢复检查核对原五个包收据，不重算旧模型。派发时由协调者建立 `docs/team/baseline-t10-m5/snapshot.json`。

唯一写入 `research/garment_prediction/coupled_m5/**`、`docs/GARMENT-COUPLED.md`、`docs/team/reports/algorithm-t10-m5.md`；既有研究、收据、报告和全局只读，不提交/派代理/改 C/App/雨情/能源/通知。

## 目标与验收

1. 明确两个计算区域与横杆中央的关系是每个情景的假设，不把中央指定为所有衣物最慢处。未测区域没有新观测，不从有限候选推断已知。只沿用现有单中央测点，不增加传感器或硬件要求。
2. 用同一份衣物水库存和温度状态推进开放/覆盖蒸发，覆盖蒸发在气腔中等量反向出现。给出不重叠面积与水流/热流表，不在 M1 完全开放扣水后叠加 M3 扣水；处理初值、参考时刻、环境切换与状态传递单位。
3. 衣物温度允许动态响应空气温湿度、日照、通风等既有驱动。先推导一致能量边界再编码：蒸发/吸湿携带焓、显热、辐射和储热的基准一致；覆盖处是否保留原对流/辐射面积须明示假设。空气/腔壁温度可采用明确受限边界，但外部热库与未建模项必须登记，不能用固定空气温度无条件证明被动结构热平衡。无需为完整性盲目增加 CFD、吸附模型或硬件。
4. 响应状态在温度变化时必须有一致物理含义。M3 的等温密度状态不能未经推导除以新饱和密度就宣称是实际 RH 传感器动态；给出明确受限观测闭合和待标定参数。凝露、超域、接触/结构变化等不能裁剪后继续。
5. 参数/方程优先复用已核对资料；必要时查一级论文/厂家资料，仅采纳其实际支持的范围，不伪装已有衣物实验。新数值均有来源或合成标签；误差未知与零分开。
6. 用退化边界和独立参考验证：零覆盖应恢复相应 M1 开放衣物解（匹配同一面积/驱动/参考焓）；明确恒温限制下与 M3 对照；封闭水量、吸湿/零初值、同温输入与能量账、环境分段切换、步长/独立积分、失败/凝露暂停均有证据。不能只靠两份复制代码相互通过。
7. 交付从当前状态到未来情景推进的明确契约，携带局部空气/响应历史及未知区状态。此包先验收统一前向模型，不直接修改 M4 的相容性结论或旧 M2b 的 ETA；后续观测更新和目标时间必须使用同一版本状态/边界，不能用未经审核的适配器拼接。
8. 所有结果为 SYNTHETIC_UNCALIBRATED，收衣授权 false，配置、单位、适用域、seed、来源指纹和复算命令齐备。没有实测时仅证明所选方程的数值与接口一致，不能宣称现实预测准确或自动获知参数。
