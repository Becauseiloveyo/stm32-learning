## 这次实际要完成的内容

目标是一个**条件情景时间计算器**及它与未来观测估计的边界。当前没有可靠的“中央温湿度→含水量”映射，不强行把接口通过的 RH 输入拿来缩窄未知材料/水量。若无法形成观测校正，输出明确的 scenario_only / observation_mapping_unavailable；这是未解决问题，不假装完成自适应估计。

1. 定义参数/初始状态集合：每项单位、来源、范围及人工选择依据明确，所有演示是 SYNTHETIC_UNCALIBRATED；不把真实材料名称当已标定参数。生成侧真值与计算侧先验分开；不知道初始水量、未测区或面料时不能悄悄取真值。
2. 给出未来条件假设：例如环境维持、日照减弱/高湿、通风改变，明确情景切换时刻与参数。实际未来天气和生成器隐藏标签不得进入在线计算。历史未来只可独立标注为预知参考，非必需功能。
3. 定义合成目标端点及预测范围：目标干基 X、是局部还是两个建模区、计算截止时刻/未来时域和有效域明确。该端点未经收衣标定，不称真实“已干”。M1 中趋近零和吸湿平衡可能使目标无法在时域达到；保持未知/超时域上界，不强制有限分钟数。
4. 对各允许成员和未来情景前推，报告条件时间包络。不能删除未达到端点、积分失败、超域或无依据的成员后只展示成功样本；每类原因和未解决上界须可见。跨越合成目标的时间只按说明的数值分辨率/定位方法给出，不因离散步长显示虚假的秒级精度。
5. 不把单次目标穿越当持续干燥保证。含再湿情景时说明“首次达到模型目标”和之后变化，暂不添加未经用户确认的固定等待时长。中央/未测区的关系保持 M2a 反例约束，不自动将中央视为最慢区。
6. 覆盖正常推进、初值/材料假设不同、环境变化、未观测区多解、时域内不达到、超域/积分失败、输入非法及无信息泄漏；对可解析极限或明确的参考求解给出数值误差证据。结果用情景范围，不标 95% 或概率；collection_authorized 恒 false。
