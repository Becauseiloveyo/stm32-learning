## 这轮执行 M1，完成后交接

M1 = 来源/状态契约＋独立的两区域前向热湿模型＋数值验证。先普通区/慢区、明确的合成闭合与独立质量账/热账；不用一次实现全部估计器、真实天气驱动、App 或设备适配。

1. 明确 X 干基 kg/kg、T °C、干质量 kg、各类面积 m²、质量流 kg/s、热流 W、时间 s，拒绝非法/非有限/缺失输入。初始水分、材料、风及辐射的来源或假设全部登记。
2. 参考冻结设计的水分/能量方程，检查变质量热容、参考焓、潜热与吸湿/雨水/排液的一致性；不要照抄一个方程再用同一右端计算残差冒充独立守恒。若需要修正，给出推导与影响供协调者审查。
3. 从开放织物两区开始，暂不加入无闭合依据的跨区水热传递。面料不强制分类；自然交换、蒸发冷却和吸湿应有合理边界。零库存用明确事件规则，禁止静默负值裁剪后宣称守恒。
4. 初版研究域沿用空气/织物温度各自 0–50°C，无冻结；超域明确拒绝或暂停。允许物理闭合不足时收窄，但必须解释缺口，不制造能运行的假参数。
5. 数值检查覆盖平衡、蒸发冷却、无日照、无强迫风、吸湿、零库存/事件、非法/超域、驱动突变、质量/能量账；做步长收敛并与独立积分法/可用参考求解器对照。容差要有尺度与误差依据，检查记录不得混入旧通过数量。
6. 生成可重放的少量合成示例，保存配置、来源、种子（确定性则 null）、实际命令和 source/artifact 指纹。重跑与你修改有关的检查，避免重复运行无关旧测试。

## 防水对模型的前置接口要求

这是本轮新增设计约束，不是实物性能事实：测湿探头需水汽交换而不能完全灌封；保护腔体/膜及积水可能改变响应或使观测失效。之后的 M2 必须区分正常有效、疑似湿润/遮挡、恢复中和健康未知；真实检测能力缺失时保留未知，不能把仿真真值当成可得传感器健康标志。

湿润、凝露、高 RH 和实际下雨不能互相直接等同。探头受水不等于整件衣物吸收了已知质量的水。模型可研究给定雨水输入，但估计器不能仅用二值雨头编造 R_j。传感器加热/充电热干扰与恢复期不能作为正常环境观测。

M1 在契约/后续计划中预留以上边界，不要求实现雨控制器、真实膜参数或防水认证。缺少膜/腔体标定参数时不能把响应时间假定为已知常数。
