# 正式 T02：气路结构比较与协议接入

这是原气路对话的第二轮任务。T01 已由协调者验收；用户要求开启下一步。只完成 ROADMAP 的 T02，T03 继续保留为预研，不标记主进度。

## 输入与所有权

- 先读 AGENTS、PROJECT、STATUS、TEAM、本任务书及 ROADMAP 的 T02。
- 已验收输入：MEASUREMENT-CONTRACT、当前 theory/protocol.py、model.py、run_simulation.py；只读导入可用，协调者本轮不改它们。验收证据见 verification/T01-review.md。
- 现有预研：PROBE-CONCEPTS、research/probe、reports/probe.md；必要背景为 theory/README 第 2–4 节及总体架构采样头部分。
- 唯一写入范围：research/probe/**、docs/PROBE-CONCEPTS.md、docs/team/reports/probe-t02.md。本轮不改 MODEL-VALIDITY-DRAFT 或第一轮报告；保留 baseline-v1 不变。
- 不改主状态／决策／路线图／工具／主测试收据，不新建对话或代理，不发送消息、提交、清理、部署或采购。

## 本轮交付

1. 将三结构、可控／观测／未知量、漏风与壁源、覆盖干扰、否决条件审查为 T02 正式候选比较。不要把开放探头当已知体积的可闭合腔，也不要把背片当已证实减少漏风。
2. 增加可复现的 T01 接入入口。优先保留第一轮独立分析及其已生成证据，新入口显式使用已验收协议，列清旧时序／窗口到新契约的映射，不另设一套可编辑默认时序。读取的源码、协议、参数和生成数据都记录指纹。
3. 以无噪声的同条件比较研究解与主模型，解释与主模型默认含噪声数值的区别。重放代表性漏风、小 K、壁源替代、非唯一参数反例和共同漏风／壁源包络；至少默认＋一个非默认协议确认窗口和阶段来自协议。无需给每种实物分配虚构性能名次。
4. 物理参数与合成真值仅用于模拟／研究比较，判定只读取合法观测；收衣授权始终 false。保持无凝露等适用域，超域记为不适用，不靠截断或调参隐去。
5. 把结构建议写成可操作的研究选择，列出每种关键歧义需要什么独立观测才能约束，以及仍不能确定什么。给出所有候选均不满足时的缩小范围方案。不得承诺实际准确率、风速范围、实测覆盖影响或专利首创。
6. 运行拥有范围内的必要检查，生成并核对全部新产物。测试应覆盖跨模型解析对照、协议变化、反例保留和新鲜度，避免只镜像实现。不反复跑无关模块。

## 验收与停止点

提交 PROBE-CONCEPTS 更新、可复现入口／新生成清单及 `reports/probe-t02.md`。报告列明文件、实际命令、结果、T01 输入指纹、理论候选、尚缺证据及协调者如何核对。第一轮分析若改动，必须重生成其相关输出；不拿旧哈希当新源码的证据。

本轮不扩展热模型、双腔模型或多周期状态机，不冻结器件和硬件尺寸。达到 T02 交付后停止，主线验收由协调者完成。
