1. 标准库优先，实现参数化 3D 轴对齐占位/净空检查和正视/侧视 SVG（文字不重叠，说明坐标/单位/合成性质）。使用明确合成衣架/主机/电池/传感器壳/雨头尺寸；官方芯片包络只作最小参考，不把裸芯片尺寸当整板。至少两种主机位置比较，不提前冻结。覆盖钩口/衣领取放、相邻衣架、横杆中央接触、参考通风/雨头暴露失败例。几何只能说明包围盒重叠/已定义净空，不可证明真实接触力、排水、射频或衣物柔性。
2. 电池容量/工作量比较和时间事件账：Wh/J/Ah/V 单位一致；每种负载声明位于负载侧或电池侧及转换效率，损失只算一次。静态基线+增量动作、不重复预算。T09 假设可复用作明示参考（0.2mW基线、0.02J/次、0.6W Wi-Fi、4.38J主动周期等，不是新硬件指标）。给至少 3 容量及正常/弱网/增加测量三工作量，不把容量自动映射为体积。无外接充电收能恒零，显式人工充电起止/输入侧功率/效率，满电弃充、拔线中止、低能量不足、无未来充电借用。至少 7/14/30 日比较可用能量与服务缺口或条件续航。
3. 给 T11 一个机器可读版本化接口文件：电池侧动作/基线、可用容量、预留门槛、充电事件、观测热干扰来源/未知、输出失败意义。功率尖峰、充电 CC/CV、容量随温度/老化、真实热恢复时长/目标 RAM 未知；不能从平均 Wh 推导峰值或软件已自动知道端口受水。
4. 充电口仅比较朝向/盖合与插拔净空，占位示意和盖好/开盖/充电/拔出状态说明，未来受水/反复插拔方案；不扩展其他防水，不新增传感器。STM32采集与本地状态，较重M6集合推演在电脑，PC耗时不折算 MCU 能耗。
5. 参数来源/单位/域、seed=null、DESIGN_ASSUMPTIONS_NOT_MEASURED、collection_authorized=false、冻结指纹、可重放JSON/SVG清单、必要测试和报告。解析检验能量守恒、纯放电/纯充电/容量饱和、精确事件边界；几何边界/失败例。所有验收须符合 ROADMAP T12，不以图片好看算通过。
