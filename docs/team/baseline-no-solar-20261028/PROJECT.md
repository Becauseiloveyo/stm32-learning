## 当前技术事实

- 已有 Python 短窗口、近似等温的腔体模型和证据判定原型，见 [理论说明](../theory/README.md)。它不模拟完整衣物含水量或数小时干燥过程。
- 测量时序与观测字段采用 [测量契约](MEASUREMENT-CONTRACT.md)，版本及实际运行配置见代码和 manifest；没有经过实物标定。
- 已生成 12 类合成情景和 60 组参数扫描。实际记录以 `theory/results/manifest.json` 及关联 CSV 为准，来源新鲜度由检查工具核对。
- 已有测试和能量预算脚本。最新测试是否仍适用，以 `verification/latest-tests.json` 的结果及源码指纹核对为准；不要仅相信文档中曾写过的通过数量。
- [模型适用性](MODEL-VALIDITY.md) 补充了温度读数、响应失配、缓变与有限壁库存分析；扩展位于 `research/validity/`，独立收据为 `verification/validity-tests.json`。真实装壳参数与判干标定仍未知；完整热与双腔模型暂缓。
- [多周期状态机](STATE-MACHINE.md) 在电脑上隔离批次、安装、启动域和完整配置，核对时间及原始观测，支持保存事件重放；独立收据为 `verification/state-machine-tests.json`。弱证据仍不授权收衣；有界 C 移植见下项，长期存储回收和掉电恢复仍待验证。
- [能量调度](ENERGY-SCHEDULING.md) 已把完整测量协议与状态机接入秒级能量仿真，区分预算完成、观测质量和联网确认；收据为 `verification/energy-tests.json`。按需省电可能伴随证据过期，外部触发、功率与收能仍是假设，尚未选定产品策略。
- [纯 C 核心](CORE-INTERFACE.md) 实现原始观测判定、多周期状态与能量原语，主机验证入口为 `firmware/host/run.py`。其固定容量耗尽会停止，长期历史回收及掉电持久化仍缺失；主机内存测算不等于已适配具体 STM32，实际验证状态以来源收据为准。
- [离线提醒契约](NOTIFICATION-CONTRACT.md) 把真实 Python 状态机接到本地持久队列、模拟服务与接收端，核对重复／迟到确认、旧状态失效和进程中断恢复。当前只生成研究复核提示；独立验收见 `verification/notification-tests.json`。SQLite 原型不等于 C 固件持久化，尚未接通真实手机或无线能量调度。
- 没有硬件实测，没有可部署的 STM32 固件，没有已接通的 App／云推送，没有整机续航或判干精度证据。
- 已补充两区域热湿模型方程、面料参数集合、独立雨情分支与通信/供电方案；尚未实现完整衣物动态预测器或雨情控制器。公开武汉 NASA 2024 数据和 PVGIS 2023 六姿态数据已下载，预算计算可复现，见 `research/design_extension/`；这些不是衣物实验或阳台实测。
- 当前本地文件尚未形成 Git 提交。恢复工作时保留工作树，不能把未提交误当成不存在。

## 暂定方案与可调整空间

候选结构是环境参考探头＋可移动局部探头，配合受控换气与恢复观察。主动方式是否保留，取决于它是否值得增加结构和耗电；不是必须实现的产品要求。

新增设计研究表面温度/日照观测和独立本地润湿探头，面料标签为可选先验。太阳能按挂衣约束优先比较随衣架的颈部小板/可调展开板，分体摆放作为可选对照；所需面积随地区、遮挡和工作量变化，不承诺全国同规格免充电。具体新增硬件仍未冻结。

[三结构比较](PROBE-CONCEPTS.md) 将单面气窗腔体作为优先研究载体，开放布点作被动对照，背片保持可拆。依据是便于约束和比较条件，尚无实际抗风或判干性能排名；具体风险和停止条件见该文档，不以“更封闭”直接推出更准确。

STM32U031、SHT45、ESP32-C3、太阳能充电候选器件及电池容量，都只是先前设计建议。详细记录见 [DECISIONS.md](DECISIONS.md)；调整时解释原因，不需要把它们当不可更改的前提。

模型中的流量、壁面放湿、噪声、时间常数和演示阈值大多是假设。物理参数入口为 `theory/model.py::Parameters`；测量时序和演示门限分别在 `theory/protocol.py::MeasurementProtocol` 与 `Gates`。情景覆盖在 `theory/run_simulation.py`，运行参数快照在生成的 manifest。不得在多个文档手工维护同一套数值。

## 理论结论的使用边界

1. 在现有模型假设下，弱信号可能来自干态表面，也可能来自大漏风或较小蒸发驱动力。不同物理参数可以产生相同曲线。
2. 这是模型内的推导与反例，不是对真实衣物模型成立性的实验验证。
3. 当前输出为水汽来源明显、弱信号未确认、条件不明；反复出现弱信号不能自动升级成已标定的收衣授权。
4. 未来产品仍以可靠收衣提醒为目标。理论阶段没有该授权分支，不意味着产品永远只能拒判；实测阶段需要独立参考、参数冻结和留出批次验证。
5. 创新性与性能优势需要具体比较证据。太阳能、Wi-Fi、差分测湿或加入 AI 本身不构成已证明的创新。
