# T10 M4：有限候选的条件相容性

这是对 M3 等温合成前向模型与一段局部观测的**有限离散候选检查**，不是连续参数集合的完备包络、SIVIA、面料识别、概率、已标定的衣物水分或收衣建议。`SYNTHETIC_UNCALIBRATED`、seed=null、`collection_authorized=false`；整衣状态未知、ETA 不可用。M3 `applicable` 只检查可观测必要条件，不能证明织物表面恒温或热账闭合。

## 输入边界

`ensemble.py::compare` 分别接收历史观测包、M2a 质量政策、M3 外部接触/热状态和传感器初态声明、显式模型适用声明和误差界、候选集，以及 `as_of_s`。观测字段沿用 M2a/M3：四通道的时间、来源、误差和接触/热历史独立检查；未知、缺失、重复样本、不适用、接触/热或响应历史不明均保留全部候选为 `information_insufficient`，不能用合成真值制造证据。模型声明需来源、签发时刻及合成结构误差、数值误差、边界保护和计算步长；这些界限若无依据，必须将声明标为 unknown，结果不足，不得设为 0。代码不能核实声明真假；`asserted` 仅指外部已声明，不代表实物证明。请求外多余字段被拒绝，消费端没有真实衣物状态、真实材料标签、生成器名称或未来实际天气字段。

候选包含预先声明的 M3 参数、固定常偏差区间与**明确列出的有限初态三元组**：X0（kg/kg 干基）、初始局部 RH 和传感器初始状态（0–1）。配置中三种初态响应是 0.49、0.50、0.51，仅是人为离散假设，不代表已覆盖其间的连续值。`discrete_support_complete=true` 仅断言这些是该离散候选在本计算里考虑的全部离散变体，不是任何物理连续域完备性的证明；如无法声明，直接信息不足，不将变体悄悄压成一个精确值。超出外部初态误差声明的离散点记录为不满足该条件；超域/数值失败的离散点单独记录且使候选为 `calculation_failed`，不视为已排除。各参数单位和软件域沿用冻结 M3 config 与 M1 registry；`ensemble_m4/config.json` 明示参数、人工选择、门限及时间。

候选的固定温度须同时落在每个环境温度及局部空气温度读数各自的声明误差区间中；其固定环境 RH 也须落在环境读数的误差区间中。本包没有温度结构误差模型，因此即使 M3 的宽泛必要门控通过，候选固定温度不满足上述条件时仍为信息不足，不能用局部 RH 排除。此检查不证明未观测的织物表面温度恒定。

## 相容规则与持久偏差

仅在外部声明模型假设、固定等温/气路、结构误差界和数值误差界均适用时，使用 M3 方程从参考时刻积分到**每个真实采样时刻**，对每个有限初态变体分别计算无偏读数 `p_i`。若观察读数为 `o_i`，观测独立误差界 `u_i` 不含所列的同一持续偏差，结构误差界 s、数值误差界 n，则该样本允许的持久偏差为：

`[o_i−p_i−(u_i+s+n), o_i−p_i+(u_i+s+n)]`。

将每个样本的区间与候选事先给出的固定偏差区间取**共同交集**；不能在每个时刻任意选择不同偏差。至少一个有效离散初态有非空交集则为 `compatible`；所有有效离散初态均远离相容时才为 `incompatible`，结果只在声明的合成条件下成立。样本的区间界是最坏情况加和，不作独立性或概率假设；偏差不得同时混入 `u_i` 以免重复预算。候选参数中的 `sensor_bias_rh` 必须为 0，持续偏差仅由单独区间给出；偏差区间同时与 M3 在参考初态、每个 RK4 中间状态及步末所检查的 `0 ≤ z/ρsat+b ≤ 1` 相交。若没有任何偏差通过这些计算检查，保留为计算失败而非观测排除。这保证的是 M3 求解器实际检查点的域，不保证步间连续轨迹不越界或真实湿度始终合法。`variant_results` 公开每个变体交集端点或失败原因，交集端点颠倒表示无交集。

M3 的步长加密差不是严格数值误差证明。示例数值误差界 0.00001、结构误差界 0.002、边界保护 0.001（均为 RH 比例）是 **合成声明**，不是物理真实性或数值严格界；交集缺口不超过边界保护时输出 `information_insufficient`。较大缺口的 `incompatible` 也只是以所声明界限确实成立为条件，不是对真实衣物的排除。真实模型/数值界无独立依据时不得使用该断言，须保留信息不足。偏差、传感器响应、壁源、温度和覆盖结构不确定时也不能盲目指定为零。

若所有候选都不相容，集合结果为 `model_or_candidate_coverage_mismatch`，不自动扩大阈值或选最近值；有任何失败或信息不足时集合为 `unresolved`。当前从不输出确定水量边界：有限点、未知候选覆盖及模型适用性不足以证明连续边界；更不提供干燥概率或真实收衣授权。

## 合成结果与独立对照

示例使用 M3 合成参数及一个人工 RH 观测窗口，环境/观测/接触和已声明初态均为合成输入。X0=0.6、Xb=0.15 与 X0=0.3、Xb=0.075 两个候选均相容；X0=0.03、Xb=0.15 在当前离散支持和合成界条件下不相容。它们不代表真实面料或全衣分布。未测区域仍未知。

独立解析极限：开放面积、覆盖面积、换气及壁源为零，初始空气和传感器 RH 均 0.5 时，理论上整个窗口预测恒为 0.5。若两次读数为 0.51/0.53、每次误差 0.001，忽略结构/数值误差的理想合成退化情景中，偏差必须分别落在 [0.009,0.011] 和 [0.029,0.031]，交集为空；逐时独立调整偏差会错误接受。代码测试同时验证有共同偏差的例子和边界保护输出信息不足。这里的零误差仅用于解析构造，不是现实传感器规格。

`as_of_s` 不早于任何输入观测包当前时刻、候选及假设声明时刻，M3 亦核查接触/热及初态证据的签发和覆盖。此前的在线输出由此前可用数据单独计算；后来取得的证据只能在较晚时刻重算，不能传到过去。代码不持久化或自动修订历史；调用方必须保存当时的输入与输出。不能仅凭字段校验识别来源方把事后实况伪装进合法输入字段。

## 与整衣时间的缺口

M3 是单区覆盖气腔、固定温度的短窗口；M1/M2b 是两区开放、热湿动态。中央区域与两区的对应、开放/覆盖面积分解、跨窗口状态和参考焓、非等温气腔/传感器、壁源库存及未知未测区域尚未统一；因此 M4 不把候选直接喂给 M2b、不新增全衣 ETA。最小连接契约需确定同一水库存和初态、覆盖与开放面积及各通量只记一次、统一温度和能量边界、从短窗口末状态携带全部不确定性，并独立验证观测与未知区的对应。缺少证据时保留情景范围或未知。

概念上使用有界误差相容性的共同交集；协调者提供 [Jaulin 与 Walter 1993 原文](https://webperso.ensta.fr/Jaulin/paper_automatica93.pdf) 的参考及其 §1 描述，本轮未独立核对原文，不声称采用该文的 SIVIA 或连续集合完备算法。M3 物理关系及局限见 `docs/GARMENT-OBSERVATION-PHYSICS.md`，旧资料只读；所有新增数值为手选合成。具体配置、单位、种子、命令和输入/产物哈希在本包 `config.json`、`results/manifest.json`。
