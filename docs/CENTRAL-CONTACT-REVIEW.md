# 横杆中央接触测量：依据、限制与待考虑建议

日期：2026-10-28。本文是理论研究和需求澄清，不是硬件选型、算法实现或性能验收。当前阶段仍零采购、零部署、无真实收衣授权。

## 1. 用户明确的方向

- 研发建议须结合现实、现有项目和可核对资料。发现具体缺口再提出补充，说明依据和代价，供用户考虑；没有依据就不增加功能。
- 目标位置已澄清为**衣架底部横杆中央**，不是衣物悬垂后的最低点或挂钩下方。
- 以衣物接触中央位置作为本装置开展衣物监测的使用条件；未接触的悬挂方式不开展衣物干燥记录。不将“所有衣物自然都会接触”写成已验证的普遍事实。
- 没有指定电容、电阻、接触开关、多个探头或新增夹子；这些仍只能是待比较方案。防水范围仍仅充电口。

## 2. 对当前项目的判断

中央位置可以作为统一安装基准。它把不同物品的使用方式约束到同一局部测量位置，值得先研究；当前证据不足以要求增加多点，也不足以证明它在所有物品中都是最后变干的位置。

[现有局部模型](PROBE-CONCEPTS.md)研究局部空气温湿度，不能因探头放在横杆上就自动成为直接含水量传感器。直接电学测湿是另一种观测模型，若后续选择，必须另写适配和来源说明，不能复用原湿度方程假称已经完成。

T10 的两区域前向模型用于表现干燥不均匀，并不要求两个物理探头，也不能自动知道中央对应普通区还是慢区。可保留该原型检查数值守恒；后续观测层需要研究中央接触区和其余区域之间的关系，是否足够可辨识尚未决定。无须为本次讨论直接扩成多区或重写已交付代码。

## 4. 目前仅有的必要补充，供用户考虑

### 接触有效性与干湿判断分开

需要避免把衣物离开测点引起的信号变化当作变干。这是用户“没接触就不记录”的前提，不是自动批准增设接触传感器。

可先在电脑情景中显式输入“已确认接触、未接触、接触未知”。未来由结构约束、可得检测证据或用户操作如何提供该信息，留待方案比较。仿真的真实接触标签不能直接送给估计器并冒充已实现检测能力。单独湿度弱信号或电容变化不足以在未经验证时同时承担两个判断。

建议的行为边界：

| 情况 | 衣物记录/预测建议 |
|---|---|
| 尚未确认接触 | 不新建有效衣物监测记录；不把环境空气读数当衣物已干 |
| 接触有效且观测适用 | 记录中央局部趋势，结合环境模型给出有范围限制的预测 |
| 风吹暂离或接触未知 | 相关样本不用于证明干燥；标记当前判断暂停或不确定 |
| 移走衣物 | 停止本批次预测；不继续发送旧的当前状态提醒，历史有效记录无需删除 |

后一列是设计建议，状态语义尚未接入正式代码。接触“确认”的具体阈值、等待时长与硬件成本均未冻结。

### 保留中央测量与整件结论的区别

中央局部读数有价值；其余部位的干燥情况仍来自模型推断。需要先检验中央与其他区域关系，在证据不足时保留预测范围。不要将“横杆处有接触”“这里被遮挡”“这里读数稳定”分别直接升级成“中央一定最慢”或“整件已干”。

现阶段没有依据必须增加多点、固定延长等待时长或指定新传感器。因此本轮只补清测量前提与来源，不增加这些功能。

## 5. 以后确需验证时的最小问题

在既有 T10 观测适配与 T12 布局工作内，优先回答三件事，不另开实现任务：

1. 无接触、干布接触、湿布接触，在所选观测方式下能否区分；假如不能，何种最少外部信息可以补足。
2. 同一湿布贴紧、轻搭、有间隙和折叠层数改变时，读数变化有多少来自几何，而非含水变化。
3. 中央局部达到目标而其余区域仍湿、以及中央因覆盖更慢两种情况，模型是否保留正确的不确定性。

计算用参数必须有来源或明确合成标签；没有论文参数就作敏感性范围，不冒充真实分布。比较结果若支持保持现有结构，就保持结构。新增设计建议先说明具体改善、代价和证据，再由用户考虑。
