# 模型适用性与误差草案

日期：2026-10-23。用于 T03 独立预研，不是正式 `MODEL-VALIDITY.md`，不表示 T02／T03 主线验收。依赖 [结构比较](PROBE-CONCEPTS.md)、[冻结基线 v1](team/baseline-v1/snapshot.json)；资料阅读范围见 [来源登记](../research/probe/sources.md)。没有硬件或真实衣物数据。

当前能支持的是短窗口内的敏感性与不可区分反例。漏风、壁源、覆盖、热状态及整件代表性都未得到独立约束，因此不能从曲线恢复唯一衣物含水量，不能输出真实准确率、剩余干燥时间或收衣授权。

## 3. 传感器动态、偏置和温差必须分开

### 3.1 共同环境变化也可制造差分

先刻意去掉腔体和衣物的真实差分：两只传感器接收完全相同的水汽压阶跃 A，初态相同。各自为一阶系统时：

```text
delta_observed(t) = A [exp(−t/tau_a) − exp(−t/tau_c)]
```

设 A=−300 Pa、τ_c=30 s、τ_a=4 s，最大正差分发生在：

```text
t_peak = ln(tau_c/tau_a)/(1/tau_a−1/tau_c) = 9.299552 s
delta_peak = 190.699054 Pa
```

真实差分全程为零。交换快慢顺序或阶跃方向会反转符号；相同 τ 则此例差分为零。见 [common-step.csv](../research/probe/results/common-step.csv)。这不表示完整腔体周期一定通过／失败；本脚本没有分类器。它说明单靠两处“差分”不能默认环境扰动已消除。

真实腔体对环境变化的物理滞后，与传感器滞后是两件事。在完整模型中先由质量平衡得到真实 e_c，再分别滤波 e_c 和 e_a；若已经如此模拟，不能额外把本式作为另一个独立噪声项相加。

S1 的 4 s 是 25 °C、1 m/s 气流下达到阶跃 63% 的规格，装壳后需重新测。高频读取也不把未知动态变快。[SHT4x V7.3，Table 1 脚注 9](https://sensirion.com/media/documents/33FD6951/6A7C10A0/HT_DS_Datasheet_SHT4x_V7.3.pdf)

### 3.2 温度偏置不是完整热物理模型

若真实两处均为 25 °C、60% RH，局部 RH 仍读 60% 而 T 单独产生正偏置，计算得到：

| 局部温度读数偏置 | 虚假差分，Pa |
|---:|---:|
| +0.5 °C | 57.30 |
| +1.0 °C | 116.10 |
| +3.0 °C | 367.07 |

相反，如果局部空气真的变为 25.5 °C，但水汽压与参考完全相同，正确 RH 应为约 58.241%；配对的正确 T 与 RH 转换仍给出零差分。完整对照见 [temperature.csv](../research/probe/results/temperature.csv)。因此，不能把上述“固定 RH、改温度读数”反例解释为所有真实温差都会同样产生假信号。

真实布表面 T_f 改变又是第三类问题：e_*=a_w e_s(T_f) 会改变；即使空气探头读数无偏，真实蒸发驱动力也可能缩小。现有单温度模型不包含 T_f 状态，不能据此算日晒、风冷或蒸发冷却下的衣物水量。

### 3.3 偏置、缓变与随机波动

近似分压偏置写为 b_e(t)=b_0+r t。常值 b_0 在恢复首尾差里可抵消，但仍改变尾部绝对差分；缓变 r 同时影响两者。按本轮恢复头 0–5 s 和尾 80–90 s，均值时刻为 2.5 和 85 s，故恢复幅度偏差为 82.5r。假设 r=0.5 Pa/s，幅度被改变 41.25 Pa；这仅是完整解析反例，没有实际漂移速率证据。

采样点间的共同热状态、壁面历史和传感器慢漂移不能当白噪声按 √N 缩小。也不能将连续相同低信号变成若干独立校准证据。

## 4. 不重复计算的误差预算

测量量 Δe=f(RH_c,T_c,RH_a,T_a)。RH 以百分数输入；令 c 为一阶偏导向量，Σ 为输入标准不确定度与协方差矩阵，则 u²(Δe)=cᵀΣc。方法使用一阶传播近似，输入不确定度必须与相应修正和分布假设匹配。[NIST TN 1297 Appendix A，式 A-3](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)

在 25 °C、60% RH 下，单探头的灵敏度为 ∂e/∂RH=31.6174 Pa／百分点、∂e/∂T=113.1057 Pa/°C。假设每只探头标准不确定度 u_RH=1 个百分点、u_T=0.1 °C，且四输入独立，得到 u(Δe)=47.4887 Pa。这复核 B1 的算例；不是 SHT45 典型 ± 精度的标准差换算，也不包括安装失配。

预算应按证据分三部分记账，尚未知的项目保留“未知”，不能强行做一个总准确率：

1. **已修正的测量误差残余**：传感器校准、成对互比、重复读数及其协方差。偏置修正后只计残余，不再把同一个原始偏置作为另一个独立项。
2. **显式动态和模型参数**：若气路、传感器 τ、壁源状态已在模型中传播，则计其参数／初值不确定度，不能又把整条模拟滞后当额外独立误差相加。若经验 τ 已包含外壳死区，就不能再用同一死区体积重复解释该 τ；需通过独立阶跃区分传感器与气路。
3. **未建模或不可界定的偏差**：覆盖、非混合、热状态、参考位置与整件代表性。没有独立约束时报告适用性缺口，不能塞入一个任意高斯 σ。没有含水量模型就不存在可传播到“含水率准确率”的合法灵敏度。

数值积分误差和浮点重合误差只用于验证计算实现，不与真实测量误差混为一谈。阈值须在参考和模型适用范围明确后确定；本轮没有调整主线阈值。

## 5. 壁源变化：已实现的有限储量反例

常量 S_w 适合短时近似，但不能无限时间供水。独立脚本增加一个只放湿、不吸湿的有限储量反例，不把它当材料本构：

```text
M_w(0) = S_0 tau_w                  单位 kg
dM_w/dt = −M_w/tau_w
S_w(t) = M_w/tau_w = S_0 exp(−t/tau_w)
V dy/dt = −D y + R_v T S_0 exp(−t/tau_w)
```

这里选择 a_w=RH_a/100、环境固定、y(0)=0，故没有独立的布面源常数项；布面仍可吸收腔内超额水汽。D=K+Q_l，a=D/V、b=1/τ_w、c=R_v T S_0/V：

```text
y(t) = c [exp(−bt)−exp(−at)]/(a−b)   当 a≠b
y(t) = c t exp(−at)                  当 a=b
```

该响应先升后降，形状不能直接认作衣物变化。脚本给 S_0=0.10 µg/s，τ_w=30／120／600 s，初始储量分别为 3／12／60 µg；从 0 到 180 s 输出 [decaying-wall.csv](../research/probe/results/decaying-wall.csv)，未叠加传感器滤波。这一情景从恢复起点 y=0 开始，与前述完整周期的初态不同，不能把两张表直接作单因素对照。

质量核对使用相对于恒定环境的超额水量：

```text
M_w(0)−M_w(t) = V y(t)/(R_v T) + integral[ D y/(R_v T) dt ]
```

右侧第二项同时包括排向环境和被环境平衡布表面吸收的水。测试用 0.01 s 梯形积分核对 180 s 守恒，允许残差 10⁻⁷ µg；并覆盖 a=b 极限。S_0=0 退回无壁源模型，τ_w 远大于窗口时可近似常量源；不是声称现实壁面有无限储量。真实吸湿、滞后、温度依赖和反向交换仍暂缓，需空白材料历史数据后才可拟合。

## 6. 暂缓实现的物理扩展及其守恒接口

### 6.1 非等温质量平衡

当 T_c 可变时，正确起点是气体中的水汽质量，而不是保持原分压方程不变：

```text
m_c = V_c e_c/(R_v T_c)
dm_c/dt = J_f + S_w + sum(q_in rho_v,in) − sum(q_out rho_v,c)
rho_v = e/(R_v T)
```

J_f 和 S_w 单位 kg/s；q 为对应位置温压下的体积流量 m³/s，不能不加条件地令不同温度处的进出体积流量相等。固定 V 时展开左侧有 V/(R_v T_c)[de_c/dt−(e_c/T_c)dT_c/dt]，遗漏温度导数会把热变化误归为水汽源。

在 T_f=T_c=T_a=T 常数、单一等体积交换 Q 且采用原来的等温闭合 J_f=K(e_*−e_c)/(R_v T) 时，乘 R_v T 即退回冻结基线方程。非等温的 J_f 本构仍未知，不能拿等温 K 无条件外推。

若以后引入一个共同布表面温度 T_f，最简候选表面能量关系需同时登记：

```text
C_f dT_f/dt = sum_j[H_fj(T_j−T_f)] + P_absorbed + P_contact − L_v J_evap,total
```

C_f 为 J/K，H 为 W/K，P 为 W，L_v 为 J/kg；J_evap,total 是该控制体两面净蒸发质量流率（kg/s）。若有液滴流入／流出、吸附热或多个布温状态，还需额外项。气体温度也不能靠任意设定的正弦曲线冒充热量守恒。由于热容量、光吸收、接触换热和表面通量均无证据，本轮不实现／拟合热模型，不生成长时干燥曲线。

### 6.2 背侧第二空气体积

挡风背片若形成非环境湿度的气袋，令 ρ_c、ρ_b 为前后水汽密度，Q_bc 为简化的等体积对称交换率。在等温、固定体积近似下可提议：

```text
V_c dρ_c/dt = J_f + S_wc + Q_ac(ρ_a−ρ_c) + Q_bc(ρ_b−ρ_c)
V_b dρ_b/dt = J_b + S_wb + Q_ab(ρ_a−ρ_b) − Q_bc(ρ_b−ρ_c)
```

相加时内部交换项抵消，满足水汽守恒。若背侧被独立证实快速跟随环境，ρ_b≈ρ_a，其交换可约化到单腔漏风；若前后充分混合，可在满足各边界条件时合并体积与源。当前并无上述证据，新增体积和交换系数又会增加未知量，故仅列接口，不用假设参数宣称背片性能。

## 7. 未来最小验证顺序

以下是后续具备条件时的验证设计，本轮不需要采购或实施。每步都要记录几何版本、材料与预湿历史、探头编号、环境、原始时戳和安装事件；先规定参考与容限，再看结果。

| 顺序 | 最小对照与记录 | 解决的问题／停止条件 |
|---|---|---|
| V1 成对观测链 | 两探头同处，温湿升降阶跃、互换位置；分别记录裸装与最终安装的响应 | 区分偏置、τ、运输延迟及温湿交叉影响；不满足重复性则先停气路归因 |
| V2 空白头与气路 | 不透水替代面、无布空白、等湿布三类分开；干／湿预处理；进出口开关和受控环境变化 | 确认空白信号、壁源历史和流量假说；空白不能直接覆盖穿布漏风。只有壁源可忽略且 τ 已约束时，空白衰减才可能给交换估计 |
| V3 装夹与风扰 | 同一参考状态布样重夹；风向／风强分级并测环境值；C 与可拆 B 配对 | 约束穿布与绕边，检查背侧是否形成独立储湿；不能只记风扇档位或用模型拟合代替独立流量证据 |
| V4 覆盖与主动影响 | 位置随机化、匹配样本／同部位交叉，比较无覆盖、O、C、B；控制探头材料和时序，独立称重／局部参考 | 确认被测位置是否因覆盖晚干或吹气提前干；超出预定容限则改结构、缩短覆盖或退回用途 |
| V5 参考与留出验证 | 定义同温湿平衡基准与收衣标准，区分绝干；按整件、日期、批次留出；记录厚处参考和测量移动事件 | 建立真正的局部／整件映射；同时报告错误提醒、延迟、有效比例与区间；未完成前没有收衣授权 |

S3 摘要中的研究做过称重校准与覆盖影响考察；这里只借鉴验证顺序，不沿用其皮肤样本的性能、时间窗或尺寸。[原始论文作者摘要](https://pubmed.ncbi.nlm.nih.gov/12709124/)

“最小”指必须覆盖的证据类型，不是已经确定足以支持产品准确率的样本数。探索批次必须与之后冻结参数的独立批次分开；反复采样或同一衣物多点不能冒充独立衣物实验。

## 8. 实际检查与正式接入限制

独立脚本产生 8 个周期情景、135 组敏感性点、共同阶跃、有限壁源、温差与覆盖算例，全部带 `SYNTHETIC_UNCALIBRATED` 标签。11 项检查通过，包含独立 RK4 对照、相等时间常数极限、源项重合、参数导数、有限壁源质量平衡、温差一致性、越界拒绝及基线／输出指纹。检查验证公式实现和证据新鲜度，不验证物理模型成立。

135 个短窗口内未跨过单温度饱和边界，但 9 个形式稳态超出边界；没有据此模拟凝露。真实冷表面可能在平均 RH 未饱和时凝露，这仍是本模型缺项。

正式接入要由协调者在 T01 验收后复核协议版本、阶段语义、有效性原因及观测字段。新增参数必须附单位、来源类别、测量条件与未知标记；真实观测接口不能读取本脚本的 `synthetic_true_*`、K、a_w、壁源真值。本轮没有修改主模型、主测试记录或任何主线状态。
