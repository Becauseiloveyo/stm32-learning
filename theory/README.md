## 1. 这一阶段要回答什么

先回答三个问题：不同物理状态会不会给出相同观测；哪些输入条件下应停止判断；结构与采样时序最需要约束哪些参数。之后再根据有依据的接口实现 STM32 固件。

本版不模拟整件衣物数小时的干燥过程。它只模拟约 140 秒的一次测量窗口，将布面水汽势在该窗口内视为固定。这样可以检查测量链路，却不能预测整件衣服还有多少克水或多久干透。完整织物模型需要内部扩散、吸脱附关系、蒸发冷却、辐射和风场等，目前没有可信参数。

## 2. 变量与边界

| 符号 | 含义 | SI 单位 |
|---|---|---|
| V | 采样腔有效空气体积 | m³ |
| e_c、e_a | 腔内与环境水汽分压 | Pa |
| e_s(T) | 饱和水汽压近似 | Pa |
| a_w | 有效表面水分活度，0–1 | 无量纲 |
| e_* | 表面有效水汽势 a_w × e_s(T) | Pa |
| K | 包含有效面积的集中传质系数 | m³/s |
| Q_l | 未受控泄漏交换量 | m³/s |
| Q_u(t) | 受控气路额外交换量 | m³/s |
| S_w | 腔壁额外释湿质量流率 | kg/s |
| τ_s | 简化的一阶湿度传感器时间常数 | s |

模型条件：近似等温、固定有效体积、腔内充分混合、一个窗口内 K 和 a_w 固定、不发生凝露。代码内部使用 SI；配置体积／流量以 mL、mL/s 便于阅读，换算时乘 10⁻⁶。腔壁参数输入 µg/s，换算时乘 10⁻⁹。

K 不是已知风速，a_w 不是衣物含水百分比。风机命令也不是实测流量。代码中 Q_u 是假设可知的交换量；实际设备尚不满足这个前提。

## 3. 从质量平衡推导短时模型

在等温条件下，用 e=ρ R_v T_K 把水汽密度模型换成分压模型：

```
V de_c/dt = K(e_* − e_c) − (Q_l + Q_u)(e_c − e_a) + R_v T_K S_w
```

令 y=e_c−e_a，则：

```
V dy/dt = K(e_*−e_a) − (K+Q_l+Q_u)y + R_v T_K S_w − V de_a/dt
```

它解释了四类影响：衣物表面提供水汽交换；气路带走或带入水汽；腔壁可能产生额外信号；环境变化本身会改变差分曲线。只有环境稳定、S_w 可忽略、参数恒定时，才可以写成简单指数恢复：

```
y(t) = y_inf + [y(0) − y_inf] exp(−t/τ_c)
y_inf = K(e_*−e_a)/(K+Q_l+Q_u)
τ_c = V/(K+Q_l+Q_u)
```

重要推论：

- 漏风增大时，湿表面也可能只产生很小的分压差。
- 环境越接近表面水汽势，蒸发驱动力越小；小信号不能直接说明含水少。
- 缩小腔体会改变速度，但不自动消除漏风和表面状态之间的歧义。
- 固定体积和稳定气路是可解释测量的前提之一；算法不能把它们当作已经解决。

相对湿度转换沿用原方案的 Magnus 形式近似，代码主动限制到 0–50 °C，不扩展到冰面、凝露或其他未建模状态：

```
e_s(T) = 610.94 exp[17.625 T/(T+243.04)]
e(T,RH) = RH/100 × e_s(T)
```

Magnus 形式与系数优化的原始研究见 [Alduchov 与 Eskridge，1996](https://journals.ametsoc.org/view/journals/apme/35/4/1520-0450_1996_035_0601_imfaos_2_0_co_2.xml)。这里的温度限制是本程序的设计边界，不是整机适用范围认证。

## 4. 可辨识性：曲线清楚也未必能反推含水量

在 e_a 固定、S_w=0、V 已知的本模型内，观测方程主要暴露两个组合量：

```
A = K + Q_l
B = K(e_*−e_a)
V dy/dt = B − [A + Q_u(t)]y
```

K、Q_l、e_* 至少是三个未知量。即使施加多个已知 Q_u，仍可能只确定 A、B，无法分别确定这三个未知量。下列两组参数就是一个解析反例，环境均为 25 °C、60% RH：

| 参数 | A 组 | B 组 |
|---|---:|---:|
| K | 0.02 mL/s | 0.04 mL/s |
| Q_l | 0.02 mL/s | 0 mL/s |
| a_w | 1.0 | 0.8 |
| K+Q_l | 0.04 mL/s | 0.04 mL/s |
| K(a_w−0.6) | 0.008 mL/s | 0.008 mL/s |

因此，两者在相同控制、初始条件和传感器动态下产生同一观测。无噪声仿真的最大差只有约 1.82×10⁻¹² Pa，为浮点运算量级。它证明的是**本模型里的参数非唯一性**，不是证明真实衣物必然严格符合本模型。

两组都不能直接贴“湿／干”真值标签。更不能根据它们的相同曲线推算整件衣物剩余水分。本版没有内部含水状态；不能凭空生成一个数值含水率作为仿真真值。

架构上的含义：需要通过可重复结构、空白对照和后续标定约束 Q_l、K 或 S_w 的影响。若这些约束做不到，应限制适用条件或评估独立补充观测。增加 AI 模型复杂度，或仅把风机分成多个档位，不自动解除这个歧义。

## 5. 传感器动态与误差

仿真把湿度传感器近似成一阶系统：d e_measured/dt=(e_c−e_measured)/τ_s。等温下它与 RH 的一阶响应等价。分段恒定输入采用解析更新，并检查 τ_s 与腔体时间常数相同的特殊情况，避免除零。

默认 τ_s=4 秒用于起始假设，另设 30 秒的慢响应情景。Sensirion 的 4 秒规格是在规定温度和气流下达到湿度阶跃 63% 的时间，装入外壳后的响应会受结构影响，不能将此默认值当作实物结果。[SHT4x 数据手册](https://sensirion.com/media/documents/33FD6951/6A7C10A0/HT_DS_Datasheet_SHT4x_V7.3.pdf)

差分分压 Δe=e_c−e_a 的一阶不确定度传播可写为：

```
u²(Δe) = Σ[(∂Δe/∂x_i)²u²(x_i)] + 协方差项
```

方法依据 [NIST 不确定度传播说明](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)。输入必须是标准不确定度，不能直接把器件“典型 ± 精度”当标准差。

仅作算例：若两探头各自的标准不确定度设为 RH 1 个百分点、温度 0.1 °C，且相互独立，在 25 °C、60% RH 下得到 u(Δe)≈47.49 Pa。这些是假设的不确定度，不是从 SHT45 规格换算出的结论，也不包含安装误差。

合成曲线另使用 0.10 个 RH 百分点的随机噪声，种子固定为 20261023；它与前面的总不确定度算例是不同概念。位置偏差、长期偏差和系统性热误差不能靠多采样自动消除。温度失配情景只模拟读数偏差，不是完整的日照与蒸发冷却热模型。

## 6. 本版算法的输入与输出

输入为时间戳、周期阶段、两处温湿度、传感器有效标记、开夹事件以及版本、单位和协议指纹。判断函数不能读取合成场景的 K、a_w、漏风量或场景名称；保存在 CSV 中的 synthetic_true_chamber_Pa 和诊断 delta_e_Pa 都不作为算法输入，分压差由温湿度重新计算。

先检查版本、单位、读数、时序与阶段完整性，再检查环境变化、高湿、接近饱和、温度失配和开夹事件。演示阈值统一由 [protocol.py](protocol.py) 的 Gates 定义，当前运行值见 [manifest](results/manifest.json)，本轮没有调节原有六项默认值。它们只用于执行流程和构造反例，**尚不是可以装机使用的阈值**。

阶段时长、采样周期、特征窗和时间／数量要求统一由 `MeasurementProtocol` 提供，模拟器和判定器接收同一协议。默认完整曲线的特征保持原值；此前硬编码的恢复下限已由完整协议起止检查替代，最大间隔由采样周期与允许倍数推导。首尾窗口锚定计划时刻，不随缺样平移。字段、单位、有效范围、错误码和旧接口迁移见 [测量协议 v1.0](../docs/MEASUREMENT-CONTRACT.md)。

| 输出 | 含义 | 产品层如何使用 |
|---|---|---|
| VAPOR_SOURCE_PRESENT | 有明显水汽恢复来源 | 不提示收衣；来源可能是衣物，也可能是腔壁 |
| LOW_SIGNAL_UNCONFIRMED | 当前窗口信号弱 | 等待更多证据；不能显示“已干” |
| UNKNOWN | 输入无效、条件不适合或响应含混 | 说明原因，之后重新获得有效窗口 |

连续弱信号只累计次数，不产生未经标定的可收衣状态；无效或强信号清空弱信号计数。这不是完整判干产品算法，而是可检验的证据处理原型。未来只有在适用场景、阈值和整件衣物参考均得到独立验证后，才可增加收衣授权分支。

未来 STM32 代码可沿相同边界拆分：观测结构→特征提取→有效性检查→证据状态→事件队列。当前交付是可运行 Python 参考实现，没有声称已经生成、编译或烧录 STM32 固件。

## 9. 接下来的零采购开发顺序

以下为原理论版本的方向说明。当前执行顺序、输入和验收统一以 [开发任务卡](../docs/ROADMAP.md) 为准；先完成协议与参数统一，再进行气路比较。

1. 用当前模型明确结构必须约束的未知量，为不同气路画参数化示意，比较可解释性与测量扰动。
2. 引入有来源的织物吸脱附、热量交换与内部扩散模型；缺少参数时保留区间并报告敏感性，不能擅自指定真实面料数据。
3. 把多周期证据处理和 [能量预算](../analysis/energy_budget.py) 接起来，比较固定复核与按需复核的能量、等待时间及无结果比例；没有实测标签时不比较产品准确率。
4. 固定数据和状态接口，再写可在电脑上测试的纯 C 核心；以后接入实际驱动，复用同一批异常测试。
5. 等具备硬件条件后，按保留的验证清单替换假设参数，并对留出的真实批次评估误报、延迟和适用范围。

小腔体测量蒸发的研究支持“恢复信号值得研究”这一方向，但原研究包含专门校准及腔体影响验证，不能直接移用其人体测量结果作为衣物性能证据。[Nuutinen 等，2003](https://pubmed.ncbi.nlm.nih.gov/12709124/)
